## Что сделать

1. **Сайт.** Выложить `ogneliss-site-deploy-2026-11-12.zip` (только
   страницы) по `site/DEPLOY.md`: `unzip -o` в каталог статики, без
   удаления. Главную и страницы Dialer собирать только
   `site/build_site.py` из репозитория OgnelissMail-archive (старая копия из
   проекта Dialer убирала ссылку на Share). Правила nginx не менялись.
2. **Выпуск на GitHub** — метка `v2.4.0`; «Что нового» страница выпуска
   берёт из `STORE_NOTES_2.4.0.md`.
3. **Проверить на телефоне**:
   - письмо-рассылка (например, от еАптеки) — логотип и баннер видны после
     «Показать изображения»;
   - письмо «Fwd: Занавеси» — открыть: фото `image0.jpeg` в списке
     вложений (если нет — долгое нажатие → «Загрузить заново»);
   - «Настройки»: в разделе «Почта» — четыре пункта, «Антифишинг» — в
     «Конфиденциальности», шрифт и масштаб — в «Оформлении».

Сервер, Xcode, разрешения Android и Play Console — без изменений. Сборка —
как у 2.2.0 (`OWNER_STEPS_2.2.0.md`, разделы 3 и 3а).
