## 1. Сервер: прокси погоды (один раз, ~10 минут)

Подробно — `server/weather-proxy/README.md`. Кратко:

1. Скопируйте папку `server/weather-proxy` из архива на сервер, например:
   ```bash
   scp -r server/weather-proxy root@<IP-сервера>:/root/weather-proxy
   ```
2. На сервере:
   ```bash
   sudo bash /root/weather-proxy/install-weather-proxy.sh install
   ```
   Скрипт сам скачает список городов GeoNames (~3 МБ), найдёт сеть Nginx
   Proxy Manager (как у push-relay) и запустит контейнер `weather-proxy`.
3. Nginx Proxy Manager (`http://<IP>:81`) → хост `ogneliss.ru` → Edit →
   **Advanced**: сначала скопируйте прежнее содержимое (вернуть при
   ошибке), затем добавьте рядом с `location ^~ /push/` раздел из README
   (шаг 2 там) — `location ^~ /weather/ { … }`. Save. Тот же раздел
   добавьте в `site/nginx-landing.conf` архива сайта, чтобы он не пропал
   при следующей выкладке сайта.
4. Проверка:
   ```bash
   sudo bash /root/weather-proxy/install-weather-proxy.sh check
   ```
   Ждём три зелёные строки: служба отвечает, поиск города работает,
   прогноз получен. Из браузера:
   `https://www.ogneliss.ru/weather/search?q=Казань` — список городов.

**Обновление прокси** (когда в архиве будет новая версия
`server/weather-proxy`): скопировать папку поверх `/root/weather-proxy` и
снова `install-weather-proxy.sh install` — контейнер пересоберётся,
список городов сохранится. Список городов — раз в несколько месяцев:
`install-weather-proxy.sh cities`.

**OAuth-прокси и push-relay обновлять не нужно** — в них ничего не
менялось. Но: приложение теперь проверяет сертификат сервера входа как у
любого сайта (раньше для него принимался любой). Сертификат GlobalSign
для ogneliss.ru и www.ogneliss.ru действует **до 29.01.2027** — продлить
заранее (`server/oauth-proxy/MAIL-TLS-OGNELISS.md`), иначе вход в Яндекс,
Mail.ru и обновление их токенов остановятся.

## 2. Сайт: политика конфиденциальности

В `ogneliss.ru/mail/privacy` добавить абзац о погоде — текст в
`docs/guides/WEATHER.md`, раздел 3 (прогноз и поиск города через сервер

чтобы при необходимости сменить или выключить адреса погоды без
обновления приложения.

## 3. Если ogneliss.ru недоступен

Что делает приложение по каждой службе — `docs/guides/SERVER_DOWN.md`.
Коротко: почта от ogneliss.ru не зависит; вход в новый ящик Яндекс/Mail.ru
сразу говорит «сервер входа недоступен»; токены обновляются с растущей
паузой без «войдите снова»; погода — последний прогноз. Совет:
наблюдение раз в 5 минут (cron) — `install-weather-proxy.sh check`,
`install-push-relay.sh check`, `curl -fsS https://ogneliss.ru/oauth/healthz`.

Silicon, Intel)** → Product → Archive → Distribute App → App Store Connect.

## 5. Проверка на телефоне

1. **Свайпы**: короткий — кнопки, длинный — первое действие сразу; в
   «Удалённых» вопрос «удалить навсегда?» — до того, как строка ушла;
   «Отмена» — строка на месте; в беседе после удаления — «Вернуть».
2. **Просмотр**: картинка во вложении — кнопка «Повернуть»; PDF на
   Android — «Повернуть страницу / все страницы»; картинка в письме
   на весь экран — «Повернуть».
3. **Фото ящика**: «Настройки → ящик → фото» — обрезка, поворот, круг.
4. **«Мой день»** (после шага 1): часы перелистываются в начале минуты;
   значок погоды → город → прогноз по часам, «Получено в …».
5. **Складной** (если есть): внутренний экран — список слева от сгиба,
   письмо справа.
6. **Ошибки**: без сети и при недоступном сервере — нет красной точки и
   строк ошибок; письмо, ушедшее в очередь, отправляется само.
7. **Exchange**: ящик с именем для входа, отличным от адреса, — входит.
8. **Чёрный экран (HUAWEI)**: после установки 1.15.1 — «Настройки →
   Расширенные → Графика». Если там «Сейчас: Skia (после сбоя …)» —
   переключилось само. Если «Сейчас: Impeller» (запись о сбое 08.11 система
   уже не хранит — она держит ~16 последних) — выбрать «Совместимость
   (Skia)» → «Перезапустить». Полистать письма с фото, открыть вложения,
   ответить и переслать — экран не чернеет. Если всё же чернеет — пакет диагностики
   (строки «Графика:» и «Память:»), `docs/guides/GRAPHICS.md`. На другом
   Android-телефоне там же — «Сейчас: Impeller»; выбор «Совместимость» →
   «Перезапустить» — приложение открывается заново, «Сейчас: Skia».
