# Ogneliss Mail — правила для Claude

Отвечать владельцу по-русски. Подробности о лицензиях — docs/LICENSING.md.

## Новые зависимости — только после проверки лицензии

Правило владельца 31.10.2026 (после истории с Exchange ActiveSync: патентное
обещание Microsoft не допускает коммерческого распространения).

Перед подключением любой зависимости — пакета pub.dev, библиотеки Gradle или
CocoaPods, SDK или фреймворка платформы, npm-пакета сервера, шрифта, иконок,
внешнего сервиса или API — проверить лицензию и условия использования:

- **Платный функционал** (платная лицензия, подписка, оплата запросов сверх
  бесплатного лимита, только коммерческие условия) — не подключать, сначала
  обсудить с владельцем.
- **Ограничительные или неясные условия** (только некоммерческое
  использование, патентные условия, ограничения по области применения,
  GPL/LGPL/AGPL, нет лицензии) — тоже сначала обсудить.
- **Бесплатный функционал** — используем, соблюдая требования лицензии: текст
  лицензии и NOTICE в приложении («Настройки → О приложении → Тексты
  лицензий»), атрибуция, где требуется, строка в таблице docs/LICENSING.md
  (раздел 2).

То же для платных ресурсов, которые тратит сама разработка (например, минуты
GitHub Actions сверх бесплатных): заметный расход — обсудить.

## Сборка и выпуск

- Версию (pubspec.yaml) не менять без просьбы владельца.
- Архив исходников — только tool/dev/make_archive.sh: в нём нет
  project.pbxproj, Runner.entitlements, Signing.xcconfig и кода базы — их
  ведёт владелец у себя.
- Файлы проекта Xcode (project.pbxproj, Runner.entitlements) не менять: что
  нужно включить в Xcode, описать владельцу словами.
