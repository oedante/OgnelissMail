# Task O1: text documents — DOCX, ODT, RTF → HTML

Shared rules: [o_common.md](o_common.md) (read it first) and [common.md](common.md).

## Result
`OfficeTextDoc` (`office_document.dart`): an HTML fragment + images (key → data URI, referenced as `<img src="cid:key">`) + `truncated`. The lead shows it like an attached e-mail: `MailBodyProcessor.heavy(html, HtmlSanitizer.sanitizeKeepingStyles)` → `MailHtmlDocument.buildAsync(..., inlineImages: images)` → `MailHtmlView` (Android/iOS WebView, JS and network off, dark theme, zoom); on Windows/macOS/Linux → `DesktopMailBody(html:, images:)` (Flutter widgets, `mail_native_body.dart`: it ignores `<style>` blocks). So:
- inline styles only (no `<style>` blocks, no classes), tags the sanitizer keeps (see `_allowedTags`/`_globalAttrs` in `lib/core/security/html_sanitizer.dart`): p, h1–h6, b/strong, i/em, u, s, sub, sup, span, br, hr, a href, img src/width/height/alt, table/tbody/tr/td/th with colspan/rowspan/width/style, ul/ol/li, div, blockquote;
- do not set font-family (except a generic `monospace` for Courier-like fonts) and do not set colour for "auto" text — the app's font and dark theme must work; explicit document colours and highlights are kept;
- sizes in pt; Word's empty paragraphs keep their height (`<p>&nbsp;</p>` or `<br>`);
- text budget: count text characters plus `OfficeLimits.blockWeight` per paragraph, table cell and row; stop at `OfficeLimits.maxTextWeight` with `truncated: true` (close open tags properly).
Put the common HTML writing (escaping, style strings, budget, cid images) into one helper file (e.g. `lib/services/documents/doc_html.dart`) used by all three readers.

## API (exact)
- `lib/services/documents/docx_reader.dart`: `class DocxReader { static OfficeTextDoc read(OfficeZip zip); }`
- `lib/services/documents/odt_reader.dart`: `class OdtReader { static OfficeTextDoc read(OfficeZip zip); }`
- `lib/services/documents/rtf_reader.dart`: `class RtfReader { static OfficeTextDoc read(Uint8List bytes, {String lang = 'en'}); }` (`lang` — app language, for the fallback code page when the file declares none: `ru`/`uk`/`be`/`bg`/`kk`/`sr` → Windows-1251, else Windows-1252)

## DOCX (ECMA-376 WordprocessingML)
Main part via `zip.officeDocumentPart()` (fallback `word/document.xml`), its rels, `styles.xml` (docDefaults, paragraph/character styles with basedOn chains; "heading 1…6"/"Title"/outlineLvl → h1–h6), `numbering.xml` (abstractNum/num/lvl: numFmt bullet/decimal/lowerLetter/upperLetter/lowerRoman/upperRoman, lvlText "%1.%2.", start, restarts of deeper levels — Word numbering is per paragraph, so render a list paragraph as a `<p>` with a computed prefix and left indent rather than ul/ol), `footnotes.xml`/`endnotes.xml` (reference → superscript number, notes listed after an `<hr>` at the end).
Paragraphs: pStyle, jc (left/center/right/both→justify), ind (left/firstLine/hanging, twips), spacing before/after, shd fill, bidi → dir="rtl", page break → a thin dashed `<hr>`. Runs: b, i, u (not "none"), strike/dstrike, vertAlign, color, sz (half-points), highlight (named colours), shd, caps/smallCaps, vanish (skip hidden), w:t (xml:space), tab, br/cr, noBreakHyphen, softHyphen, sym. Fields: fldSimple; complex fields (fldChar begin/separate/end, instrText) — show only the result; HYPERLINK field → link. w:hyperlink r:id → external http/https/mailto `<a href>`; w:anchor → plain text. w:ins/w:moveTo — shown, w:del/w:moveFrom/delText — skipped; sdt/sdtContent, smartTag, customXml — recurse. Tables: tblGrid widths, gridSpan → colspan, vMerge restart/continue → rowspan, tcPr shd → background, borders (tblBorders/tcBorders/style "Table Grid" → 1px solid; none → no border), nested tables. Images: w:drawing (wp:inline/wp:anchor → a:blip r:embed, wp:extent cx/cy EMU → px = EMU/9525) and VML w:pict/v:imagedata r:id; `zip.image(...)`; EMF/WMF/too big → skipped. mc:AlternateContent → mc:Choice, or mc:Fallback when Choice gave nothing; never both. Text boxes (w:txbxContent) → their paragraphs in place. Headers/footers/comments — skip.

## ODT (OASIS OpenDocument text)
`content.xml` (automatic styles + office:body/office:text), `styles.xml` (common and default styles), style chains (style:parent-style-name, family). text:h (outline-level → h1–h6), text:p, text:span, text:a (xlink:href), text:s (text:c), text:tab, text:line-break, text:list/list-item/list-header (bullet/number styles, nesting → ul/ol with list-style-type or prefixes), text:note (footnotes as in DOCX), text:section, text:table-of-content/index-body (render body), text:tracked-changes (skip), bookmarks/fields (text content). Style properties: fo:font-weight, fo:font-style, style:text-underline-style, style:text-line-through-style, fo:color, fo:font-size (pt or %), fo:background-color, style:text-position (super/sub), fo:font-variant, fo:text-transform, fo:text-align (start/end/center/justify), fo:margin-*, fo:text-indent, fo:border. Tables: table:table-column (number-columns-repeated — capped), table:table-row(s)/header-rows, table:table-cell (number-columns-spanned/rows-spanned; covered-table-cell skipped), cell background and borders. draw:frame → draw:image (xlink:href "Pictures/…" via `zip.image`; svg:width/height in cm/mm/in/pt → px) and draw:text-box (paragraphs). Check `zip.odfMimeType` (text or text-template; anything else → damaged) and `zip.odfEncrypted` (→ encrypted).

## RTF (Microsoft RTF 1.9.1)
Tokenizer for groups, control words (with signed parameter), control symbols, `\'hh`, `\uN` (negative → +65536) with `\ucN` skipping, `\binN` (skip N bytes). Ignore `\*` destinations you don't know; skip fonttbl after reading `\fcharsetN` per font (204 → cp1251, 0 → cp1252, 238 → 1250, 161 → 1253, 162 → 1254, 177 → 1255, 178 → 1256, 186 → 1257, 222 → 874; others → the document's `\ansicpgN`); colortbl → colours; stylesheet, info, header/footer — skip; footnote → as in DOCX if simple, else skip. Code pages via `enough_convert` (Windows-125x). Character: \b \i \ul \ulnone \strike \fsN \cfN \highlightN \cbN \super \sub \nosupersub \plain \caps \scaps \v (hidden). Paragraph: \par \pard \ql \qc \qr \qj \liN \riN \fiN \sbN \saN \line \tab \page; `{\listtext …}`/`{\pntext …}` — include as text (that is the list number). Tables: \trowd \cellxN \intbl \cell \row → `<table>`. Fields: `{\field{\*\fldinst HYPERLINK "url"}{\fldrslt text}}` → link. Pictures: `\pict` with `\pngblip`/`\jpegblip` hex data → image (size from \picwgoal/\pichgoal twips); wmf/emf → skipped. Group depth cap, and stop on the text budget.

## Tests (examples, not exhaustive)
Fixtures (generated by your script): a DOCX with headings, bold/italic/underline/colour, bullet and numbered lists (two levels), a table with colspan and rowspan, a small PNG, an external hyperlink, a footnote, Cyrillic text; the same document converted by LibreOffice to ODT and RTF; a hand-written Word-style RTF in Windows-1251 (`\ansicpg1251`, `\'e0`) and one with `\u` escapes. Check structure of the HTML (headings, list prefixes, colspan/rowspan, cid image present in `images`, link href), that it survives `HtmlSanitizer.sanitizeKeepingStyles` (images, spans, colspan) and that `MailHtmlDocument.build(..., inlineImages:)` keeps the image. Hostile: deep nesting, huge generated document (truncated), malformed XML (damaged), ODT with encryption-data (encrypted), RTF with unbalanced braces (shows what it can).
