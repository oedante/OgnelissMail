# Task O2: spreadsheets — XLSX, ODS, CSV → sheets, shown as a grid

Shared rules: [o_common.md](o_common.md) (read it first) and [common.md](common.md).

## Model and API
`lib/services/documents/doc_sheets.dart` (pure Dart): `class OfficeSheetsDoc extends OfficeDoc` with `final List<DocSheet> sheets` and `truncated` (any sheet truncated). Design the rest yourself for memory and speed, roughly: `DocSheet` (name, shown row/column count, sparse rows of cells, column widths and row heights in logical pixels, merged ranges, frozen rows/columns from the file, `truncated`), cells with display text already formatted plus a style index into a shared style list (bold, italic, underline, strike, size, text colour, fill colour, horizontal/vertical alignment, wrap; numbers right-aligned by default like Excel). Hidden sheets, rows and columns are not shown.

Readers (exact signatures):
- `lib/services/documents/xlsx_reader.dart`: `class XlsxReader { static OfficeSheetsDoc read(OfficeZip zip, {String lang = 'en'}); }`
- `lib/services/documents/ods_reader.dart`: `class OdsReader { static OfficeSheetsDoc read(OfficeZip zip, {String lang = 'en'}); }`
- `lib/services/documents/csv_reader.dart`: `class CsvReader { static OfficeSheetsDoc read(Uint8List bytes, {String fileName = '', String lang = 'en'}); }`
`lang` is the app language: decimal and thousands separators and the short date form for locale-dependent formats (ru: `1 234,56`, `05.11.2026`; de: `1.234,56`; en: `1,234.56`, `11/5/2026`; choose sensibly for the 27 app languages).

Caps (constants in your file, documented): at most ~10 000 rows and 256 columns per sheet and ~300 000 non-empty cells per document; beyond → `truncated`. Never allocate from declared sizes.

## XLSX (ECMA-376 SpreadsheetML)
`workbook.xml` (sheets: name, r:id, state hidden/veryHidden; workbookPr date1904), its rels → worksheet parts; `sharedStrings.xml` (si/t and rich r/t → plain text; skip rPh; can be huge — events); `styles.xml` (numFmts, cellXfs: numFmtId/fontId/fillId/alignment horizontal, vertical, wrapText; fonts b/i/u/strike/sz/color; fills patternFill fgColor) with colours rgb, theme (theme1.xml clrScheme, with tint) and indexed (the default 64-colour palette). Worksheet (events over `zip.readHead`): sheetFormatPr defaults, cols (min/max/width/hidden; Excel width units → px ≈ width*7+5), sheetViews/pane (frozen xSplit/ySplit), sheetData row (r, ht, hidden), c (r, t = s/str/inlineStr/b/e/n, s), v, is; formulas — show the cached value only; mergeCells. Number formats: General (like Excel: up to ~11 significant digits, no float noise — 0.1+0.2 shows 0.3), built-in ids (0–4, 9–22, 37–40, 45–49), custom format strings: sections `pos;neg;zero;text`, `0`, `0.00`, `#,##0`, `%`, `E+`, literal text in quotes/backslash, `[$₽-419]`/`[$-F800]` currency/locale tags, `[Red]` colours (may ignore), date/time tokens (y, m, d, h, s, AM/PM, `[h]` elapsed). Dates from serial numbers (1900 leap-year bug, date1904). Errors (#DIV/0!) as text; booleans TRUE/FALSE.

## ODS (OASIS OpenDocument spreadsheet)
`content.xml` (events if large): office:spreadsheet/table:table (table:name; hidden via table style display false), table:table-column (number-columns-repeated, style → column width, visibility collapse), table:table-header-rows, table:table-row-group, table:table-rows, table:table-row (number-rows-repeated, row height, visibility), table:table-cell (number-columns-repeated, number-columns-spanned/rows-spanned, office:value-type; the formatted text is in text:p — use it, with text:s, text:tab, text:a, several text:p → line breaks), table:covered-table-cell. Repeated empty trailing rows/columns (`number-rows-repeated="1048000"`) must cost nothing: only expand up to the last non-empty cell, capped. Styles (automatic in content.xml, common in styles.xml): table-cell-properties fo:background-color, text-properties, paragraph-properties fo:text-align; table:default-cell-style-name of columns. `zip.odfMimeType` (spreadsheet or template; else damaged), `zip.odfEncrypted` (→ encrypted).

## CSV (RFC 4180) and TSV
Encoding: BOM (UTF-8, UTF-16 LE/BE); valid UTF-8 → UTF-8; otherwise Windows-1251 when the bytes look Cyrillic or `lang` is Cyrillic, else Windows-1252 (`enough_convert`). Delimiter: `sep=;` first line (Excel hint); `.tsv` → tab; else the most consistent of `,` `;` tab `|` over the first lines outside quotes (Russian Excel writes `;` and cp1251). Quotes with `""`, line breaks inside quoted fields, CRLF/LF/CR. Numbers right-aligned. Read only the head (cap) of a big file → truncated.

## Viewer widget
`lib/features/mail/widgets/doc_sheet_view.dart`: `class DocSheetView extends StatefulWidget { const DocSheetView({super.key, required this.doc}); final OfficeSheetsDoc doc; }`. It fills the space it gets (the screen puts it in an Expanded page of a PageView — horizontal drags inside the grid must scroll the grid, not switch pages; check how `PdfView`/`InteractiveViewer` coexist with the PageView in `attachment_preview_screen.dart`).
- Sheet switcher when there is more than one sheet (bottom tabs like Excel, or chips; use the app's UI components and tokens).
- Grid: pinned header row (A, B, C…) and pinned row-number column, lazy in BOTH directions (a 10 000 × 100 sheet must scroll smoothly; consider `TwoDimensionalScrollView` from the Flutter framework or a painter-based grid), merged cells, widths/heights from the file, styles, wrap, alignment, frozen panes from the file if feasible. Mouse wheel / trackpad and scrollbars on desktop.
- Tap a cell → its full text in a bar above the grid (selectable/copyable), like Excel's formula bar — long text cut by the cell becomes readable.
- Pinch zoom (about 0.5×–3×) is welcome if it stays smooth.
- Theme: default cells — theme surface/onSurface; explicit fills kept, with readable text on them (auto text on a light fill → dark); grid lines subtle in both themes.
- Empty sheet → `l10n.tr('docSheetEmpty')`; truncated sheet → a small note `l10n.tr('docSheetTruncated')`.

## Tests
Fixtures: an XLSX (openpyxl) with two sheets (one hidden third), Cyrillic, numbers with formats (`#,##0.00`, `0%`, date `dd.mm.yyyy`, a custom `[$₽-419]` currency), a formula with cached value (openpyxl writes no cached values — set them by editing the XML in your script or let LibreOffice recalculate and save), merged cells, bold/fill/colour, a column width; the same converted by LibreOffice to ODS; CSV in UTF-8 with commas and in cp1251 with `;`, quoted multi-line field, `sep=` line, TSV. Hostile: ODS with huge repeated rows/columns, XLSX with `dimension A1:XFD1048576` and a single cell, sharedStrings index out of range, malformed XML, missing styles.xml. Widget test: grid shows header letters, row numbers, a cell value, switching sheets, tapping a cell shows its text.
