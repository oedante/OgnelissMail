# «Что нового» — 1.8.12 (128)

В 1.8.12 изменилось только поведение на iPhone и iPad: архив и другой файл
из письма, которые «Просмотр» iOS не показывает, открываются сразу листом
«Поделиться» — там архиватор (например, iRAR) и «Сохранить в Файлы»; у ZIP с
паролем — подсказка, что «Файлы» его не откроют. Раньше открывался пустой
экран просмотра с неработающей кнопкой «Скопировать в …» (замечание
29.10.2026). Для Android изменений нет.

**App Store.** Если 1.8.11 (127) ещё не загружена — загрузите сразу 1.8.12
(128): текст из STORE_NOTES_1.8.11.md (блок А или Б, ru, en, de, fr) и в конец
— строка ниже. Если 1.8.11 уже загружена — только строка ниже.

**Google Play.** Если 1.8.11 (127) ещё не отправлена — отправьте сразу 1.8.12
(128) с текстом из STORE_NOTES_1.8.11.md. Если уже отправлена — 1.8.12 в Play
можно не выпускать; выпускаете — блок «Мелкие исправления» ниже.
