# Погода в «Моём дне»: условия, прокси на сервере, переключение

Сделано 07.11.2026 (1.15.1, просьба владельца «в мой день добавить
переворачивающиеся часы и погоду»). Код приложения:
`lib/services/weather/weather_service.dart`,
`lib/features/my_day/weather_view.dart`; сервер: `server/weather-proxy`.

## 1. Решение владельца и как оно выполнено

07.11.2026 владелец принял условия MET Norway (Terms of Service,
https://api.met.no/doc/TermsOfService, раздел «Use of AI agents» требует,
чтобы их принял человек) с условием: **данные пользователей сторонним
сервисам не передаём.**

Поэтому:

- приложение не обращается к MET Norway и к поиску городов напрямую:
  прогноз и поиск идут через прокси на сервере Ogneliss
  (`https://www.ogneliss.ru/weather/…`, `server/weather-proxy`);
- MET Norway видит только адрес сервера и координаты города (до сотых,
  ~1 км), не IP и не устройство человека; прокси хранит ответ до
  `Expires` — один запрос к MET на город для всех пользователей;
- Nominatim (OpenStreetMap) не используется: его правила требуют отдельного
  решения разработчика и умеренного числа пользователей. Поиск города —
  по списку GeoNames (CC BY 4.0) на том же сервере, наружу запрос не уходит;
- местоположение телефона не используется: город выбирает человек;
- организация может запретить погоду через MDM (ключ `block_weather`).

**Что нужно от владельца:** развернуть прокси (`server/weather-proxy/README.md`,
три шага: установщик, раздел `location ^~ /weather/` в Nginx Proxy Manager,
проверка). До этого в окне погоды — «Прогноз недоступен», в поиске города —
«Поиск не удался». Выключить погоду в приложении целиком —
`WeatherApi.termsAccepted = false` (или файл из раздела 2).

## 2. Переключение без обновления приложения: services.json

Приложение перед запросом погоды или поиском города читает (не чаще раза в
сутки) файл **https://ogneliss.ru/mail/services.json**:

```json
{
  "weather": {
    "forecast": "https://www.ogneliss.ru/weather/forecast",
    "geocoder": "https://www.ogneliss.ru/weather/search"
  }
}
```

- Адрес `https://…` — замена (служба с тем же форматом ответа). Только
  https и без параметров в адресе; иначе — адрес по умолчанию.
- Пустая строка `""` — выключено: прогноза нет, или в окне поиска «Поиск
  города сейчас недоступен».
- Файла нет (404) или ключа нет — адреса по умолчанию (как выше).
- Сайт недоступен — последние полученные адреса.

Файл не обязателен; выложить его с адресами по умолчанию стоит, чтобы при
необходимости поменять одну строку. Кладётся рядом со страницами `mail/`.

## 3. Текст для политики конфиденциальности (ogneliss.ru/mail/privacy)

> **Погода в «Моём дне» (по желанию).** Погода выключена, пока вы не
> выберете город. Местоположение устройства не используется. Название
> города для поиска и координаты выбранного города, округлённые примерно
> до 1 км, отправляются на сервер Ogneliss. Сервер ищет город в своём
> списке городов (GeoNames) и запрашивает прогноз у MET Norway
> (Норвежский метеорологический институт) от своего имени: сервисам
> погоды не передаются ни ваш IP-адрес, ни данные устройства. Сервер
> Ogneliss не сохраняет адреса, координаты и поисковые запросы. Раз в
> сутки приложение читает с ogneliss.ru список адресов этих служб.
> Организация может запретить погоду через MDM (ключ `block_weather`).
