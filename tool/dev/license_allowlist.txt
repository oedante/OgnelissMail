# Исключения проверки лицензий (tool/dev/license_check.py; правило владельца
# 31.10.2026 — CLAUDE.md, docs/LICENSING.md, раздел 5).
#
# Сюда — только пакеты, которые проверка не пропускает (GPL/LGPL/AGPL, SSPL,
# BUSL, «некоммерческое», лицензия не распознана), но владелец решил, что
# зависимость допустима. Одна строка — один пакет:
#
#   [pub:|npm:]пакет  лицензия-как-используем  причина
#
# Без приставки — пакет pub. Причина обязательна. Примеры:
#
#   pub:some_pkg  MIT  двойная лицензия MIT или GPL-3.0; используем по MIT (решение владельца ДД.ММ.ГГГГ)
#   npm:other     BSD-3-Clause  поле "license" в package-lock.json пустое; LICENSE в пакете — BSD-3-Clause
#
# Исключение, которое больше не нужно, проверка отмечает предупреждением.
#
# 31.10.2026: исключений нет — все 226 пакетов pub и 68 пакетов npm
# (server/oauth-proxy) под разрешёнными лицензиями.
