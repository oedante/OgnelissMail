# Дизайн-система Ogneliss — Dialer и Mail

Версия 1 — 07.11.2026. Решение автора: «Dialer и Mail должны иметь одинаковый
интерфейс и схожий функционал во всех экранах и функциях; единая дизайн-система —
один документ на оба приложения».

## 0. Как этим пользоваться

- **Один документ, два места.** Этот файл лежит одинаковым в обоих репозиториях:
  `OgnelissDialer/docs/OGNELISS_DESIGN_SYSTEM.md` и
  `OgnelissMail/docs/OGNELISS_DESIGN_SYSTEM.md`. Правка — в обоих одним заходом,
  с одинаковым текстом. Подробности своего приложения остаются в своих документах
  (`OgnelissDialer/docs/DESIGN_SYSTEM.md`, комментарии `lib/core/theme/*` почты), но
  не противоречат этому.
- **Источник правды для чисел** — блок `tokens` ниже. Код сверяется скриптом
  (один и тот же файл в обоих репозиториях):
  - Dialer: `python3 scripts/design_tokens_check.py --other ../OgnelissMail`
  - Mail: `python3 tool/ui/design_tokens_check.py --other ../OgnelissDialer`

  Скрипт читает значения из кода своего приложения (а с `--other` — и второго),
  сравнивает с документом и проверяет, что блоки `tokens` в двух копиях
  документа одинаковы. Расхождение — код выхода 1. Пометка «# пока различается» —
  известное расхождение из раздела 8: о нём пишется, выход не портится.
- **Меняя приём в одном приложении — меняй и в другом**, или запиши расхождение
  в раздел 8 с причиной. Так уже живёт расчёт цветов (`ThemePresetMath.kt` ↔
  `theme_palette.dart` / `appearance.dart`).
- Чего нет в документе — решается по смыслу ближайшего описанного приёма и
  дописывается сюда.

## 1. Принципы

1. **«Воздушный» вид** (Dialer 1.7.0, Mail 1.8.0). Границы — цветом и отступом,
   а не линиями, рамками и тенями. Разделы — подписи без полос, между строками
   списка линий нет, портреты без колец, карточки без рамок, нижняя панель плоская
   с линией 1 dp сверху. Полосы, линии, кольца и рамки — только в теме высокого
   контраста (Dialer `OgnelissSurfaces.outlined`, Mail `OgnelissLook.outlined`).
2. **Токены вместо чисел.** Отступы — `Space.*`, радиусы — токены и масштаб
   «Скругления», цвета — роли темы (`colorScheme`, свои поверхности), значки —
   один набор. Проверки: Dialer `prebuild_check.py` (правило 40), Mail
   `tool/ui/ui_lint.py`.
3. **Цвет — смысл, а не украшение.** Акцент (`primary`) — выбор, состояние,
   управление. Красный — необратимое. Зелёный в Dialer — только звонок.
   Значки кнопок нейтральные.
4. **Одна рука.** Частые действия — внизу, под большим пальцем: нижняя панель,
   её центральная кнопка, массовые действия в режиме выбора.
5. **Тихо: выполнить или пропустить, а не объяснять** (решение автора
   07.11.2026). Приложение не показывает ошибки, предупреждения и пояснения:
   оно выполняет действие (или запасной путь), а если нельзя — молча пропускает
   и пишет причину в журнал разработчика. Сообщение человек видит **только
   о критичной проблеме, которую может решить лишь он сам**: без его действия
   не будут работать звонки, SMS или уведомления о них. Такое сообщение —
   один раз, когда проблема действительно случилась, коротко и с кнопкой туда,
   где это исправить. «Отменить» после действия — не сообщение об ошибке,
   остаётся. Успех не подтверждается (видно и так; Android 13+ сам показывает
   скопированное).
6. **Настройки «Оформления» действуют везде:** тема, акцент, скругление, плотность,
   шрифт, масштаб. Новый экран берёт значения только из темы — тогда настройки
   на нём работают сами.
7. **Доступность:** цель касания ≥ 48 dp, контраст текста ≥ 4,5 : 1 (расчёт 4,6),
   подписи для TalkBack/VoiceOver, «Уменьшить движение» выключает анимации жестов.

## 3. Типографика

Шрифты: системный, Roboto, Noto Serif, Roboto Condensed (Android); выбор — «Оформление».
Размер числом в экранах не задаётся — только стили темы (и `.copy`). Исключение —
экран вызова Dialer (имя и номер видно издалека).

| Роль | Стиль | Dialer сейчас | Mail сейчас |
|---|---|---|---|
| Заголовок экрана | `titleLarge` | 22 | 22 |
| Имя в строке списка | `listName` / `titleSmall` | 14 Medium | 14 w500 (не прочитано — w700) |
| Вторая строка (текст, номер) | `bodyMedium` | 14 | 14 |
| Третья строка, время | `bodySmall` | 12 | 12 |
| Подпись раздела | `titleSmall`, `primary`, обычным регистром | 14 Medium | 14 w500 |
| Заголовок дня | та же роль, текст ПРОПИСНЫМИ: «СЕГОДНЯ», «ВЧЕРА», «29 октября · ЧЕТВЕРГ» | да | да |
| Кнопки | `labelLarge` | 14 Medium | 14 w500 |
| Подписи под значками | `labelMedium` / `labelSmall` | 12 / 11 | 12 / 11 |

Размеры одинаковые — умолчания Material 3 (**Д1, пересмотрено 12.11.2026**: автор взял
Ogneliss Mail за образец; у Dialer было на 1 sp крупнее при своём масштабе 90 %).

### Масштаб интерфейса и размер шрифта

Одинаково в обоих (Mail `ui_zoom.dart`, `main.dart` ↔ Dialer `ui/theme/UiScale.kt`):

- **Масштаб интерфейса:** «Авто» (по умолчанию) · 85 · 90 · 95 · 100 · 110 %. «Авто» —
  наименьшая сторона экрана / (412 dp × t), где t — множитель шрифта (крупный шрифт
  учитывается наполовину); от 0,97 — без изменений; не меньше 0,85; шаг 1 %; от 600 dp —
  не трогается. Масштабируется всё: размеры и текст.
- **Размер шрифта:** ползунок 80–160 % с шагом 10 % — поверх размера шрифта системы;
  итог (система × настройка) не больше 1,6.
- В настройках: ползунок с подписью «Размер шрифта · 100 %», варианты масштаба в ряд,
  под ними — что делает «Авто» и «Сейчас: N %».

## 4. Цвета

- **Темы и акценты** — одинаковые (блок `tokens`), расчёт цветов из них — один
  алгоритм в двух языках: Dialer `ThemePresetMath.kt` ↔ Mail `theme_palette.dart`
  и `appearance.dart` (`AccentFit`: светлая — L ≤ 45 %, тёмная — S ≤ 75 %, L ≥ 70 %,
  контраст 4,6 : 1).
- **Два вида страниц:** СПИСОК (журнал, SMS, контакты, лента писем — страница
  белая, строки во всю ширину) и НАСТРОЙКИ (настройки, карточка контакта,
  «О приложении» — серо-голубая страница, белые карточки-группы радиуса
  `radius.card` без рамки).
- **Строка:** обычная — цвет страницы; выбранная — `secondaryContainer`;
  непрочитанная — точка или жирнее имя (см. раздел 5).
- **Смысловые цвета:** необратимое — `error`; звонок (Dialer) — `CallGreen`,
  только звонок; SMS (Dialer) — `MessageBlue`; карты SIM (Dialer) — `SimColors`;
  ящики (Mail) — цвет ящика. Свайпы — непрозрачные светлые смеси цвета действия
  с фоном и тёмный значок того же тона.
- **Портрет без фото** — буквы имени на светлом круге. Цвет — см. Д8.
- Тени не используются, кроме всплывающего поверх (карточки по удержанию, меню,
  плавающая дата, строка отмены).

## 5. Компоненты

| Компонент | Правило |
|---|---|
| **Строка списка** | Портрет по плотности (`density.*`), поле по бокам 16, справа время; две строки: имя и текст; непрочитанное — имя жирнее, время `primary`, счётчик. Линий нет |
| **Заголовок дня** | «СЕГОДНЯ / ВЧЕРА / 29 октября · ЧЕТВЕРГ», при прокрутке — **плавающая дата** сверху по центру; над лентой «↑ N новых» |
| **Закреплённые** | Подпись «Закреплённые» и строки сверху ленты; закрепление — из карточек по удержанию |
| **Архив** | Строка «Архив · N» сверху списка (только если не пуст) и пункт «Ещё → Архив». Новое событие возвращает из архива |
| **Шапка раздела** | 56 dp. Слева — название открытого (раздел, папка) `titleMedium` и строка под ним; справа — поиск, фильтр (точка — включён), «⋮» с действиями над списком. Mail — `AppBar` ленты, Dialer — `SectionTopBar` (2.2.1) |
| **Меню** | Правая кнопка нижней панели. Панель справа во всю высоту (не шире 360 dp и 86 % экрана): сверху «Папки» списком (значок, название, непрочитанные; открытая — заливкой), ниже — плитки: 4 колонки, зазор 6, высота 56, радиус 8; с подписью — две колонки, значок — одна. Mail — `MailDrawer` + `TileGrid`, Dialer — `OverflowMenu` + `SmsFolderRows` (2.2.1) |
| **Нижняя панель** | Плоская, линия 1 dp сверху. Разделы — пилюли 56 × 32, выбранный — `secondaryContainer`; **в центре — главное действие** раздела (Mail — «Создать», Dialer — клавиатура набора; см. Д6). Свайп по панели — соседний раздел (Dialer; см. Д12) |
| **«Ещё»** | **Плитками** (решение автора 08.11.2026): круглые кнопки 48 dp с подписью до двух строк, как быстрые действия карточек по удержанию; 4 в ряд на телефоне (на широком окне — до 6), **по категориям** с подписью — «Список», «Инструменты», «Приложение», каждая обычно в один ряд: колонки совпадают, у пункта постоянное место; необратимое («Очистить журнал») — отдельной строкой `error` ниже |
| **Карточки по удержанию** | Удержание строки — карточка над размытым фоном: шапка (портрет, имя), ряд круглых кнопок частых действий, группы «Ещё». Обе программы |
| **Режим выбора** | Включается **удержанием портрета** (удержание строки — карточки). Касание отмечает, **протягивание по столбцу отметок** — отмечает подряд (Mail; Dialer — с 2.1.3); сверху — крестик и «Выбрано: N»; действия — см. Д2. «Назад» выходит |
| **Свайпы по строке** | Настраиваются **отдельно для каждого раздела** (Mail: лента, беседа; Dialer: журнал и контакты, SMS). Одно действие — по порогу; два-три — панель кнопок, ждёт нажатия. Значок у края растёт к порогу. Открыта одна строка |
| **Отмена** | После удаления, архива, блокировки — строка «Удалено · Вернуть» с кольцом-отсчётом **над нижней панелью**, ленту не сдвигает (см. Д4) |
| **Сообщения** | Только критичное, требующее действия человека, — плашкой с кнопкой, один раз; всё остальное — в журнал разработчика (принцип 5, Д4) |
| **Диалоги** | Только для необратимого и выбора; «Отмена» и действие (`error` для необратимого) |
| **Настройки** | Группы с подписью сверху, внутри карточка; строка — значок `primary`, название, пояснение, «›» если ведёт дальше; поиск по названиям, пояснениям и ключевым словам; «Вернуть как было» у изменённых |
| **Пустое состояние** | Значок и короткий заголовок; без пояснений; кнопка — только если нужна для работы |
| **Ширина на планшете** | Содержимое по центру не шире 720 (настройки) / 860 (списки) — см. Д10 |
| **Значки** | Material Symbols Rounded; выбранное — залитый вариант |

## 6. Жесты и отклик

| Жест | Смысл (одинаков в обоих) |
|---|---|
| Касание строки | Открыть; в режиме выбора — отметить |
| Удержание строки | Карточки действий |
| Удержание портрета | Режим выбора с этой строкой |
| Свайп по строке | Действия раздела (настройки свайпов) |
| Свайп по нижней панели | Соседний раздел (Dialer) — см. Д12 |
| «Назад» | Закрыть шторку / выбор / поиск, потом экран |

Длительность удержания — см. Д5. Вибрация: короткая — выбор и открытие,
средняя — удержание, сильная — необратимое; на свайп — короткая в момент,
когда строка переходит порог действия (Д9), только при включённой вибрации.

## 7. Тексты

Обращение и тон одинаковые. Одно действие — одно слово в обоих приложениях:
«Удалить», «В архив», «Вернуть из архива», «Закрепить» / «Открепить», «Выбрать все»,
«Ещё», «Отмена» (в диалоге) / «Вернуть» (в строке отмены). Языки интерфейса вручную —
en, ru, de, fr; остальные — автоперевод магазина.
