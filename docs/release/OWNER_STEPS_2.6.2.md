## 1а. Сайт: политика конфиденциальности — иконки организаций

В политике Ogneliss Mail 1.10 (раздел 6.3 «Иконки организаций», все языки:
`mail/privacy.html`, `mail/en/privacy/index.html`, `ru/mail/privacy.html`,
`de/mail/privacy.html`, `fr/mail/privacy.html`) сказано, что настройка
«по умолчанию выключена». С 2.6.2 она по умолчанию **включена**. Что
поменять (версия политики — 1.11, дата — день выхода 2.6.2):

- RU: «Настройка по умолчанию включена (с версии 2.6.2); её можно
  выключить: Настройки → Почта → Безопасность → „Показывать иконки
  организаций“. Организация может запретить её политикой MDM
  (block_external_services).»
- EN: “The setting is on by default (since version 2.6.2); you can turn it
  off in Settings → Mail → Security → “Show organisation icons”. An
  organisation can block it with the MDM policy block_external_services.”
- DE/FR — то же по смыслу.

Остальное в разделе (значок сайта запрашивается у самого сайта
отправителя и видит только IP-адрес устройства; логотип BIMI — у сервера
Ogneliss, только домен; не для «Спама», рабочей почты Exchange и доменов,
похожих на бренды) остаётся верным. Исходников сайта 2.6.1 (архив
`ogneliss-site-2.6.1-changes.zip` делала другая сессия) в этой сессии нет
— пришлите папку сайта, и я соберу архив изменений, как для 2.6.1.

Выложите вместе с выходом 2.6.2: до неё политика 1.10 верна.

## 2. Что увидят тестировщики

- «Поручения → Сводка»: сверху чипы «Все · Исполняю · Контролирую ·
  Поручил» (с точкой цвета роли и числом) и выбор ящика, строка
  «Просрочено · На проверке · Срок на неделе», ниже — диаграмма «Ход
  работ». Строки окрашены по роли, у проекта под ним — его этапы, срок —
  «до 14.11» у конца полосы (прошедший — красным). Нажатие на строку
  открывает поручение. На телефоне диаграмма листается вбок и открывается
  на сегодняшнем дне.
- Проект → «План»: мои этапы подсвечены цветом роли.
- Календарь: поручения со сроком — цветом роли, подпись «Исполняю · срок
  сегодня» (или «Поручил», «Контролирую», «Помогаю», «Наблюдаю»).
- «Поручить» → кнопка «Чек-лист»: пункты видны у исполнителя. В карточке
  поручения отметка или новый пункт — под чек-листом подсказка «Изменения
  чек-листа уйдут участникам через несколько секунд», через 20 секунд
  другая сторона получает письмо «Чек-лист изменён: ✓ …, + …» и видит те
  же отметки.
- Иконки организаций (если включены «Настройки → Почта → Безопасность →
  Показывать иконки организаций»): у писем Ozon и других сайтов, где
  значок есть только на www, — значок вместо буквы; в карточке
  отправителя (нажатие на имя) — та же иконка.
- «Настройки → ящик»: сверху чипы всех ящиков, нажатие открывает
  настройки другого ящика (и в «Расширенных настройках»).
- Иконки организаций у новых установок и у тех, кто настройку не трогал,
  — сразу включены (логотип BIMI или значок сайта вместо буквы).
- Компьютер (Windows, macOS): письмо со сложной вёрсткой (рассылки
  магазинов, банков) — в окне браузера, как на телефоне. «Настройки →
  Почта → Лента и письма → Открытие писем → Сложные письма — в окне
  браузера» включена у всех; переключение сразу меняет открытое письмо. Выключить «Простые
  письма без браузера» — в окне и простые письма.
- Если на компьютере письмо всё равно упрощённое — «Журнал для поддержки»:
  строка «Сложные письма в окне: …» скажет, есть ли WebView2 (Windows),
  сколько писем окно показало и почему отказало в последний раз.
