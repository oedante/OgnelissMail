# Task U1: Telegram-like themes, mail list density, optional open/close animations

Owner's request (31.10.2026), Ogneliss Mail 1.9.x. The owner likes the current UI; changes must look native and polished on phone, tablet and desktop, light and dark (and AMOLED). Theme code: lib/core/theme/app_theme.dart (AppColors, AppTheme, page transitions SlideFadePageTransitionsBuilder / NoPageTransitionsBuilder), settings: lib/features/settings/providers/settings_provider.dart (has uiAnimations default false, reduceMotion, dynamic colour flag), lib/features/settings/screens/general_settings_screen.dart and accessibility_screen.dart (find where theme mode, dynamic colour, font are chosen), mail list row: lib/features/mail/widgets/email_list_tile.dart, mail screen: lib/features/mail/screens/mail_detail_screen.dart, router: lib/core/navigation/app_router.dart. Screenshot harness: tool/shots/shots_test.dart (golden-style screenshots; see how it is run, tagged `shots`).

## 1. Themes like Telegram
- An "Оформление" (appearance) screen (or extend the existing place where the theme is chosen — do not duplicate settings): a live preview card at the top (a mini mail list row + a short message bubble/header rendered with the selected theme, like Telegram's chat preview), then:
  - Theme presets, 6–8 tasteful ones, each working in light and dark where it makes sense (e.g. Классика (current), Небо, Океан, Лес, Закат, Графит, Полночь (AMOLED black)). Current look stays the default ("Классика").
  - Accent colour: palette of ~12 swatches + "Свой цвет" (simple hue/saturation picker without new dependencies, or check licence of any picker you add).
  - Background tint of lists/conversation (none / subtle tint / soft pattern is optional — keep it cheap to render).
  - Corner radius (cards, sheets, bubbles): small / medium / large.
  - Keep Material You dynamic colour as an option; define clearly how it interacts with presets (e.g. dynamic colour overrides the accent).
- Everything persists via the settings provider and applies instantly app-wide (ThemeData built in AppTheme). Check contrast (WCAG AA for text) in all presets, light and dark.

## 2. Mail list density
- Setting "Плотность ленты": Компактная / Обычная (current, default) / Просторная. Affects EmailListTile: vertical padding, avatar size, preview lines (compact: subject + sender on fewer lines, 0–1 preview line), also conversation rows and archive lists that use the same tile. Keep tap targets ≥ 48 dp in compact where they are interactive.

## 3. Optional animations — OFF by default
The owner: previous animations were slow, so these are opt-in ("Анимация открытия письма", default false; also disabled when reduceMotion is on):
- Shared-element transition from the list row to the message: avatar and subject "fly" into the message header (Hero). Do NOT animate the WebView/platform view; the message body may fade in after the transition. The mail view already hides the WebView behind a snapshot during route transitions — keep that.
- Close the message with a downward swipe on phones (like Telegram's media viewer): drag the page down, release past a threshold → pop; otherwise spring back. Must not conflict with vertical scrolling of the message (only when scrolled to the top), with horizontal swipes between messages, with the WebView pinch/pan, or with text selection.
- Measure: no extra rebuilds of the list when the setting is off (zero cost when disabled).
