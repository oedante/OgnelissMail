# Перевод на Windows: Bergamot (решение владельца 08.11.2026)

Перевод писем на Windows без отправки текста наружу и без большой LLM —
движком Bergamot (тот же, что в переводчике Firefox). Остальные платформы
не меняются: Android — ML Kit, iPhone/iPad/Mac — Apple Translation.

исходниках (мы не меняем — используем как есть), в приложении — текст
лицензии и ссылка на исходники. Платного ничего нет.

## Как устроить

1. **Движок — своя DLL** `bergamot.dll` с маленьким C-интерфейсом
   (`bg_load(model_dir)`, `bg_translate(handle, utf8_text, is_html)`,
   `bg_free`), собранная из bergamot-translator в GitHub Actions на
   Windows **один раз на версию движка** (ручной запуск отдельного
   workflow, ~40–60 минут Windows-раннера; результат — артефакт выпуска,
   обычная сборка приложения его только скачивает). Расход минут —
   однократный, не на каждую сборку.
2. **Dart** — `BergamotTranslator implements Translator` через `dart:ffi`,
   перевод — в отдельном изоляте (модель держит память ~100–200 МБ, текст
   письма — по абзацам, HTML — режимом движка с разметкой).
3. **Модели — по требованию**: при первом переводе с языка «Скачать
   модель ru→en (~30 МБ)?» — это действие человека, поэтому вопрос
   допустим (правило ошибок). Источник — выпуск моделей Mozilla
   (Google Cloud Storage Firefox Remote Settings) или свой зеркальный
   каталог на ogneliss.ru (тогда не зависим от Mozilla; при недоступности
   ogneliss.ru — запасной адрес Mozilla). Модели хранятся в папке данных
   приложения, удаляются в «Настройки → Перевод».
4. **Определение языка** — Bergamot его не делает. Без новых зависимостей:
   по алфавиту (кириллица/латиница/иероглифы — уже есть в
   `mail_translation.dart`) и по частоте служебных слов для латинских
   языков; при сомнении — язык из настроек «переводить с».
5. **Пары языков**: у Mozilla модели в основном «язык ↔ английский»;
   ru↔de — через английский (два шага), это делает и Firefox.

## Объём и порядок

- DLL и workflow сборки — 1–2 дня (проверка — сборка Windows в CI);
- Dart-часть, скачивание моделей, настройки, тесты — 2 дня;
- проверка владельцем на Windows — список шагов в OWNER_STEPS выпуска.

Первым делом — workflow сборки DLL (ручной запуск), чтобы увидеть время и
размер, до остальной работы.
