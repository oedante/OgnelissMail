# Поручения: что взято из Jira и Битрикс24 (12.11.2026)

Просьба владельца 12.11.2026: «подбери из интерфейса Jira и Bitrix, что нам
лучше взять для удобства постановки задач, выполнения и контроля этапов и
отчётности по ним, приложения файлов в ответах, сводных данных и визуальных
отчётов по одной задаче и по нескольким сразу. И надо добавить, с какого
аккаунта (почтового ящика) отправлено поручение».

Отбор — под нашу модель: сервера нет, всё ходит обычными письмами
(`TASK_WORKFLOW_DESIGN.md`, решения 1 и 4), исполнитель может отвечать из
любой почты. Поэтому берём то, что работает поверх писем и не требует
общего хранилища. Проекты с этапами — `ASSIGNMENT_PROJECTS.md`.

## 1. Сделано сейчас

| Задача | Откуда | Как у нас |
|---|---|---|
| **С какого ящика** | Битрикс24: «Постановщик» с порталом; Jira: «Reporter» | Карточка: «Отправлено с» / «Получено на» — портрет и адрес ящика. При постановке и в редакторе проекта — выбор ящика (несколько ящиков). В списке — значок ящика у портрета и фильтр «Все ящики / ящик»; то же в «Сводке» |
| Постановка: важность | Jira: приоритет; Битрикс24: «Важная задача» | «Важное» при постановке: значок «!» в списке и карточке, важные — первыми в группе, тема письма «Важное поручение», отметка `imp=1` — у исполнителя тоже «Важное» |
| Постановка: файлы | Jira, Битрикс24: вложения в задаче | «Добавить файлы» в «Поручить»: копия у себя и вложения в письме |
| Выполнение: результат с файлами | Битрикс24: «Результат» задачи, комментарий с файлами; Jira: комментарий с вложениями | «Готово» спрашивает, что сделано, и даёт приложить файлы; в карточке — блок «Результат»: последний ответ «Готово» (текст и файлы), от кого и когда. «Сообщить о ходе работ» — тоже с файлами |
| Контроль: возврат с причиной | Битрикс24: «Вернуть на доработку» с комментарием | «Вернуть на доработку» — только с текстом (что доработать), можно с файлами |
| Контроль: роли | Битрикс24: «Делаю», «Помогаю», «Поручил», «Наблюдаю» | Вкладки «Я поручил» / «Мне поручили» и фильтры «Контролирую», «Помогаю», «Наблюдаю»; в строке — своя роль |
| Сводка по нескольким | Jira: панель (статусы, «Создано и решено», по исполнителям); Битрикс24: «Эффективность» | «Поручения → Сводка»: действующие, просрочено, на проверке, выполнено за период, доля в срок, среднее время; полоса статусов; исполнители (или постановщики) — в работе, просрочено, выполнено, доля в срок; по неделям — поставлено и выполнено; проекты на одной диаграмме. Фильтры: «Я поручил / Мне поручили / Все», 30 / 90 / 365 дней, ящик |
| Сводка по одному проекту | Jira: отчёт эпика; MS Project: план и факт | Проект → вкладка «Сводка»: этапы принято / всего, просрочено, наибольшее отклонение, дней до срока; статусы этапов; исполнители; план и факт по этапам (срок → когда принят, отклонение в днях) |
| Отчёт | Jira, Битрикс24: выгрузка отчёта | «Отправить отчёт» (в «Сводке» и в проекте): новое письмо с кратким текстом и отчётом HTML во вложении — показатели, по людям, просроченные, проекты с планом и фактом. Открывается в любом браузере, печатается в PDF |
| Ящик проекта | — | В шапке проекта — ящик (если ящиков несколько) |

## 2. Отложено — предложить владельцу

| Что | Откуда | Почему не сейчас |
|---|---|---|
| Доска по статусам с перетаскиванием (Канбан) | Jira Board, Битрикс24 «Канбан» | Список уже сгруппирован по срокам и статусам; доска удобна на планшете и компьютере — сделать вторым видом списка, если владелец попросит |
| Повторяющиеся поручения | Битрикс24 «Повторять задачу» | Нужен планировщик, который отправляет письма без участия человека (фоновая работа на телефоне ненадёжна) |
| Учёт времени и оценки | Jira Time tracking, Битрикс24 «Учёт времени» | Для поручений руководителя избыточно |
| Метки (теги), компоненты | Jira Labels, Битрикс24 «Теги» | Мало пользы без общего хранилища: метки не видны исполнителю |
| Перетаскивание полос на диаграмме | Jira Timeline, MS Project | Сроки меняются в карточке этапа или «Сдвинуть» (письмо исполнителю) |
| Отчёт в Excel | Битрикс24 выгрузка | HTML открывается везде и печатается; Excel — новая зависимость (проверка лицензии) |
| Статусы чужих этапов у участника | Jira (общая база) | Нет общего хранилища: участник видит свои этапы и план из письма проекта |

## 3. Как считаются цифры

- **Выполнено** — работа принята (статус «Выполнено»); дата — время
  принятия. **В срок** — принято не позже дня срока (без срока — в срок).
- **Действующие** — не выполненные и не снятые. **Просрочено** — срок
  прошёл, работа не принята.
- **Среднее время** — от постановки до принятия, по выполненным за период.
- Строки проектов в сводке не считаются — считаются их этапы.
- Расчёт — `lib/services/assignments/assignment_stats.dart`, отчёт —
  `assignment_report.dart`, экраны — `assignments_summary_screen.dart`,
  блоки графиков — `assignment_charts.dart` (без библиотек графиков: у
  каждой отметки — подсказка, у графика — легенда и числа).
