## Сборка

Как у 2.2.0 — `OWNER_STEPS_2.2.0.md`, разделы 3 и 3а. Архив распаковать
поверх папки проекта; `config/dart_defines.json` — тот же.
iPhone и Mac: первая сборка ядра Rust — несколько минут, сборщик сам
ставит Rust 1.97.1 и цель платформы (в 2.2.1 падало «could not compile
`cfg-if`»). Если `rustup` спросит — можно заранее:
`rustup toolchain install 1.97.1 --profile minimal --target aarch64-apple-ios --target aarch64-apple-darwin --target x86_64-apple-darwin`.

## Проверка на устройстве (пока сделано)

- **Компьютер и планшет**: слева нет узкой полосы разделов; «Написать» и
  «Почта · Календарь · Контакты · Задачи» — над «Избранным»; в календаре и
  контактах — та же панель. Шпилька «Папки» → панель уходит, в шапке ленты —
  ☰: по нему панель выезжает, шпилькой — закрепляется снова.

- **Первый запуск на компьютере или планшете** (или после сброса настроек
  вида): вопрос «Как открывать письма?» — «Справа», «Скрыта» (на весь
  экран), «Снизу»; выбор держится, меню «⋮» ленты → «Область чтения» меняет.
- **Настройки на компьютере и планшете** (окно шире 840 точек): слева
  список, справа раздел. Выбрать «Настройки почты» → справа, без «Назад»;
  внутри перейти глубже → «Назад» справа возвращает к разделу; выбрать в
  списке другой раздел → он справа вместо открытых. Поиск (лупа над
  списком) → найденное справа. «←» над списком — закрыть настройки. Сузить
  окно (или повернуть планшет) — как на телефоне.
- **Gmail**: в `config/dart_defines.json` `GOOGLE_DESKTOP_CLIENT_ID` — ID
  клиента «Desktop app» (не Android); через час после входа на телефоне
  Gmail больше не просит «Войти снова».
- **Рассылка в окне браузера**: письмо «You were mentioned in a post»
  (Google Cloud Security Community) — текст на всю ширину письма, без
  широкой серой колонки слева.

Сборка — как у 2.2.0 (`OWNER_STEPS_2.2.0.md`, разделы 3 и 3а).
