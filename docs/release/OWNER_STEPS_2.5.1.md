## 4. Проверить на устройствах

1. **Поручение** человеку, записанному как «Фамилия Имя» (например,
   «Ситников Дмитрий»), — письмо начинается «Добрый день, Дмитрий,»; если
   в почте есть его письма с полным ФИО — «Добрый день, Дмитрий
   Александрович,». Приветствие ящика выключено («Подписи → Приветствие в
   письме → Без приветствия») — письмо поручения без приветствия.
2. **Редактор**: «Написать» тому же человеку — то же обращение по имени
   (раньше при «Фамилия Имя» без «-ов/-ин» бралась фамилия).
3. **Пользователю с Mercury**: после обновления висящие письма удалить
   кнопкой «Delete» (они уже доставлены, «Send now» даст дубль); проверку
   HELO в Mercury можно вернуть — приложение пишет `EHLO [192.168.1.67]`.
