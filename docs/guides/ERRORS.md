# Ошибки и пояснения пользователю

Правило владельца 08.11.2026: «не выводить пользователю ошибки и
пояснения, а выполнять или пропускать действия. Пользователю нужно знать о
критических ошибках, когда нужны его действия, а не любые ошибки».

## Показывать (`showInlineError`, уведомление, плашка)

Только когда без человека не обойтись или есть риск потерять данные:

- письмо не отправлено и не будет отправлено само (размер, отказ сервера,
  очередь переполнена); ответ на приглашение не ушёл; отзыв письма не
  удался;
- черновик, заметка, событие, задача не сохранены;
- нужно войти снова, сертификат сервера не совпал, запрет организации
  (MDM), вошли не в тот ящик;
- нет папки «Архив», «Спам» или «Удалённые» — её нужно выбрать;
- человек ждёт файл, а он не открылся или не сохранился (вложение в
  предпросмотре, «Сохранить», экспорт, PDF, журнал);
- сервер отказал в операции с папкой, которую человек сам запросил
  (создать, переименовать, переместить, удалить, очистить);
- выбранный человеком файл не подходит (фото ящика, импорт настроек,
  сертификат S/MIME).

## Не показывать (`quietError`, `quietNotice` — только в журнал)

- временные сбои: нет сети, сервер или прокси входа недоступен, тайм-аут,
  HTTP 5xx и 429, Exchange просит подождать — приложение повторит само
  (`looksTransientError`); красная точка синхронизации — только для
  нетиповых ошибок, где нужны действия;
- частичные сбои массовых действий (часть писем не перенеслась — они
  остались в списке и видны);
- перевод не удался или нечего переводить — кнопка просто возвращается;
- пустые результаты и пояснения («нет шаблонов», «буфер обмена пуст»,
  «перевод…», «готовлю PDF», «ушло в очередь»);
- состояние, которое и так видно на экране (вложение с ошибкой — значок на
  самом вложении).

## Как писать новый код

1. Сначала — повторить или пропустить: очередь, повтор с паузой, кэш,
   прежние данные.
2. Ошибку — в журнал (`AppLogger`), без личных данных.
3. Показывать — только по списку выше, коротко, что сделать человеку.
4. Внутри окна, которое человек открыл для действия (поиск города, выбор
   файла), можно спокойное состояние без слова «ошибка»: «Поиск города
   сейчас недоступен».
