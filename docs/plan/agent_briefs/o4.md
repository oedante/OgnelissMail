# Task O4: preview of old Office files — .xls, .doc, .ppt

Owner (04.11.2026): accepted. Old binary formats are common in Russian work mail (1C exports .xls, old .doc). Today they show «Документы старого формата Office 97–2003 … Откройте файл в другом приложении». Rules: [r2_common.md](r2_common.md) and [o_common.md](o_common.md) (security rules for untrusted files apply in full).

Licences: MS-CFB, MS-XLS, MS-DOC, MS-PPT are on the Microsoft Open Specification Promise list (no commercial restriction; the lead records it in LICENSING.md). Implement from those specifications; no third-party code.

## Wanted
- `lib/services/documents/cfb_reader.dart` — Compound File Binary (v3 512-byte and v4 4096-byte sectors): header, DIFAT, FAT, mini FAT/mini stream, directory (red-black tree — just walk all entries), stream read by name/path. Hard limits: file size (`OfficeLimits.maxFileBytes`), sector chains (detect cycles, cap length), number of directory entries, stream sizes (`OfficeLimits.maxPartBytes`), total read budget. Damaged → `OfficeDocError.damaged`.
- `xls_reader.dart` (MS-XLS, BIFF8 in the "Workbook"/"Book" stream) → `OfficeSheetsDoc` (reuse `doc_sheets.dart` builders and `sheet_format.dart` number formats, `lang`): BOF/EOF, BoundSheet8 (hidden sheets skipped), SST with CONTINUE, LabelSst, Label, Number, RK, MulRk, BoolErr, Formula (cached value; string result from the following String record), Blank/MulBlank (styles only), XF/Format/Font (number format, bold/italic/colour basics, fill if simple), ColInfo (widths), Row (heights, hidden), MergeCells, Date1904, Window2/Pane (frozen panes). FilePass (encrypted) → `encrypted`. BIFF5 and older → `legacy` (keep the message). Caps as in `SheetLimits`.
- `doc_reader.dart` (MS-DOC, Word 97+) → `OfficeTextDoc` via the shared HTML writer (`doc_html.dart`): FIB, table stream (0Table/1Table), CLX piece table → text (compressed cp1252 pieces vs UTF-16; use the FIB language/code page where needed — Russian docs!), paragraphs (\r), page/section breaks, tables (cell \x07 / row ends) as simple tables, fields (\x13 code \x14 result \x15 → show the result), hyperlinks if simple; basic run formatting (bold/italic/underline/size) from CHPX if feasible; pictures may be skipped. fEncrypted → `encrypted`; Word 6/95 → `legacy`.
- `ppt_reader.dart` (MS-PPT) → `OfficeSlidesDoc`, text-first: slide size from DocumentAtom, per slide its text (SlideListWithText / TextCharsAtom / TextBytesAtom, title vs body by TextHeaderAtom) as text boxes on a plain slide; pictures if easy (Pictures stream blips), otherwise skipped. Encrypted → `encrypted`.
- Integration (you own these parts): `OfficeFormats` (doc/dot, xls/xlt, ppt/pps/pot as formats), `office_reader.dart` (OLE: an OOXML name with an `EncryptedPackage` stream → `encrypted`; a legacy name or an OLE file with a Word/Excel/PowerPoint stream → the legacy reader by content, so a .doc renamed .xls still opens), the legacy branch of `AttachmentPreviewScreen.opensInApp` (Android/desktop: legacy files open in the app when their preview type is on — `DocPreviewSettings`; iPhone/iPad: Quick Look shows them, unchanged).
- Fixtures: produce .doc/.xls/.ppt from the existing fixtures with LibreOffice (`soffice --headless -env:UserInstallation=file:///tmp/lo_o4 --convert-to doc|xls|ppt`), Cyrillic included, plus a hand-made Windows-1251 case if LibreOffice writes UTF-16 only. Hostile tests: cyclic FAT/DIFAT, huge sector counts, truncated file, bad directory, encrypted (FilePass / fEncrypted), BIFF5.
