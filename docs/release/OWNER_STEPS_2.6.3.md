## 1. Тег для сборки на GitHub: `v2.6.3`

После слияния PR в `main`:

```bash
git fetch origin
```
```bash
git tag -a v2.6.3 -m "Ogneliss Mail 2.6.3" origin/main
```
```bash
git push origin v2.6.3
```

CI соберёт Android, iOS и macOS без подписи, Windows и Linux; страница
выпуска заполнится из `STORE_NOTES_2.6.3.md`. iOS и macOS для TestFlight —
у себя в Xcode, как обычно (архив исходников — `tool/dev/make_archive.sh`).

Тексты магазинов: 2.6.2 в магазин не выходила — полные тексты из
`STORE_NOTES_2.6.3.md`; выходила — короткий раздел «Исправления и
улучшения» там же.

## 2. Что проверить

- Ящик Google, вошедший до 2.6.2: «Настройки → ящик Google → Войти
  снова», согласиться с новыми разрешениями. Через минуту-две после
  синхронизации у писем людей из контактов и «Других контактов» — фото
  профиля Google. В журнале — «Фото собеседников Google: в профилях N,
  поставлено M» (или «нет разрешения …», если согласие не дано).
- Иконки организаций: открыть письма Ozon и Сбера, затем «Журнал для
  поддержки». В строке «Иконки организаций: …» — «без значка: …» (что
  ответил сайт — отдельной строкой «Значок сайта <домен>: …») и «без
  подтверждения DMARC: <домен> (причина)». Пришлите журнал — по нему
  будет видно, что мешает.
