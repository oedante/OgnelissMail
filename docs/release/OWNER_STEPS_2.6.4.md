## 2. Что проверить

- **Значки компаний.** Открыть ленту: у Google, Utair (utair.ru), РЖД,
  Аэрофлота, СДЭК, Stripe, Statuspage — значок, а не буква (сайты без
  значка спрашиваются заново один раз, после первой синхронизации). Где
  буква осталась — «Журнал для поддержки», строка «Значок сайта <домен>:
  …» объясняет почему (тайм-аут — сайт не отвечает из вашей сети).
- **Письма с буквой и «нет pass» в сводке** (Apple, OpenAI, Anthropic):
  в журнале строка «Значок: <домен> не подтверждён сервером ящика — …» с
  заголовком проверки; пришлите журнал — по нему видно, что написал
  сервер.
- **Фото Google.** «Настройки → ящик Google → Войти снова»; в журнале
  строка «OAuth (google): токен получен — …»: «выданы все разрешения» или
  «не выданы: contacts.readonly, contacts.other.readonly» (пока Google не
  одобрил новые разрешения — так и будет).
- **Очистить корзину** в Exchange и в Gmail (боковое меню → корзина →
  «Очистить корзину»): письма уходят и с сервера (проверить в Outlook /
  Gmail в браузере).
- **Календарь Google**: в журнале нет строк «DAV REPORT … TimeoutException»
  подряд каждые 15 минут; если календарь не успевает — одна строка
  «CalDAV google: не успел ответить календарь «…»».

## 3. Третий архив 2.6.4 (18.11): прокси, сертификаты клиента, клавиши

Версия та же (2.6.4+162). Если 2.6.4+162 уже загружена в магазин —
скажите, подниму номер сборки.

**Mac, перед сборкой в Xcode.** У плагина `ogneliss_native_http` теперь
есть часть для Mac (прокси системы через CFNetwork). Файлы проекта Xcode
и Runner.entitlements менять не нужно — достаточно обновить поды:

```bash
flutter pub get
```
```bash
cd macos && pod install && cd ..
```

(`flutter build macos` делает это сам.) iPhone и iPad — как обычно,
`pod install` в `ios` подхватит новые файлы плагина.

**Что проверить:**

- **Прокси.** В сети с прокси (или с PAC в настройках Wi-Fi / системы)
  ящики Exchange и IMAP синхронизируются, письма уходят. В «Журнале для
  поддержки» строка «Прокси» — что решено для серверов ящиков. Без прокси всё работает как раньше.
- **Сертификат клиента** (если есть сервер, который его требует):
  «Настройки → Безопасность → Сертификаты клиента → Добавить сертификат»,
  файл .p12/.pfx, пароль, домены. На Android — ещё «Сертификат
  устройства»: откроется системное окно выбора сертификата.
- **Клавиши на компьютере.** Сразу после запуска J/K и стрелки ходят по
  ленте, Delete удаляет, Ctrl+R — ответ; на Mac — ⌘R, ⌘J (переслать),
  ⌘⌫ (удалить), ⌃Q (прочитано). Справка — «Спец. возможности → Сочетания
  клавиш».
- **iCloud** после «требуется вход»: «Войти снова» — пароль уже в поле
  точками, «Войти» без ввода; после этого ящик снова проверяется.
- **Названия ящиков** — долгое нажатие на «Почту»: «Работа», «Семья»,
  адрес под названием.
- **Настройки**: «Почта → Чтение → Картинки в письмах»; «Аккаунты →
  Синхронизация»; «Лента и письма» — «Иконки организаций» и «Область
  чтения» (на планшете и компьютере).
