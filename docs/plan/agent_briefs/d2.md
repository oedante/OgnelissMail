# Task D2: tablet and desktop closer to Outlook

Owner (04.11.2026): "Мы так до конца и не доделали UI планшетов и десктопа с референсом как Outlook" — accepted list below. Rules: [r2_common.md](r2_common.md).

## Today
Wide layouts (`lib/widgets/common/adaptive_layout.dart` with `PaneSplitter`, folder pane / list / reading pane), `PaneNavigator` (`lib/widgets/common/pane_navigator.dart`: `isInside`, `push`) — reply/forward open inside the reading pane since 1.11.0. Hover actions and hover checkbox in the list (`email_list_tile.dart`, `mail_list_screen.dart`), keyboard shortcuts (`lib/widgets/common/keyboard_shortcuts.dart`), right-click menu on list rows. Attachments open as a full-screen route (`openAttachment` in `lib/features/mail/screens/attachment_preview_screen.dart`).

## Wanted
1. **Multi-select like Outlook** in the message list on devices with a keyboard/mouse: Ctrl/Cmd+click toggles a message, Shift+click selects the range from the last clicked message, Ctrl/Cmd+A selects all loaded messages, Esc clears. Works with the existing selection mode and its batch actions/command bar; touch behaviour unchanged.
2. **Reading pane position** (Outlook «Область чтения»): «Справа» (today), «Снизу» (list on top, message below, with a horizontal splitter whose position is remembered like the folder pane width), «Скрыта» (list full width, the message opens like on the phone). A setting where the other wide-layout settings live (find where the folder pane width / Outlook-style options are set; if nowhere, the "Вид" appearance screen). Only for wide layouts; phones unchanged.
3. **Attachment preview inside the reading pane**: when the message is shown in the reading pane (`PaneNavigator.isInside(context)`), `openAttachment` opens `AttachmentPreviewScreen` inside the pane (back returns to the message), like Outlook; elsewhere — as today. Open-externally/save buttons keep working.
4. **Drag an attachment out** to Explorer/Finder/desktop: investigate only. Flutter has no built-in drag-out; list candidate packages with licences, native parts and build impact (e.g. Rust toolchains), and stop — do not add a dependency (the owner decides).
5. Keep phone layouts and existing tests unchanged; tablet portrait/landscape and desktop window resizing must not break.

## Tests
Widget tests: Ctrl/Shift/Ctrl+A/Esc selection on a list with a fake repository/provider overrides (look at existing list tests); reading pane position switch (right/bottom/hidden) renders the expected structure at 1280×800; attachment opened from a message inside the pane stays inside the pane (find the preview screen under the PaneNavigator) and back returns to the message.
