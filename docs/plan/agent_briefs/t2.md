# Task T2: a better translation offer

Owner (04.11.2026): the offer "сбоит и предлагает другие языки"; accepted proposals below. Rules: [r2_common.md](r2_common.md).

## Today
- `lib/features/mail/widgets/mail_translation.dart` — `MailTranslationController` decides `phase = offer` via `shouldOfferTranslation` (`lib/services/translation/translation_languages.dart`) from `_detectLang` (sample = reply part, `mainScriptSample`, `refineCyrillicLang`).
- Android `android/app/src/main/kotlin/com/ogneliss/mail/TranslationBridge.kt` `detect`: ML Kit `identifyLanguage` (threshold 0.5); if "und" — the best of `identifyPossibleLanguages` with threshold 0.2. That weak guess is also used to OFFER translation — the source of wrong languages. iOS `ios/Runner/AppDelegate.swift` (TranslationBridge, NLLanguageRecognizer, ≥ 0.5) and macOS `tool/desktop/macos/MainFlutterWindow.swift` have their own detect.
- Settings: "Перевод" section (`translation_settings_section.dart`): offer on/off, never-translate languages, Wi-Fi only, downloaded models.

## Wanted
1. **Offer only on a confident detection.** Native detect returns the language and whether it is confident (Android: `identifyLanguage` result ≠ "und" = confident; the 0.2 fallback = not confident; Apple: best hypothesis ≥ 0.5 = confident, else the best one as a weak guess). The banner/chip offer appears only when confident (plus the existing "other script" case when nothing is detected). When the user explicitly taps "Перевести" from the message menu, a weak guess may be used (or the language is asked, as today). Keep Swift changes inside the existing files (no Xcode project change).
2. **Phone languages count as known.** New switch in the Translation settings: «Языки телефона — не предлагать перевод» (default on): languages of `PlatformDispatcher.instance.locales` (normalized with `normalizeLang`) are treated like the never-translate list for the offer. The existing never-translate list stays.
3. **«Всегда переводить с …»**: a list of languages translated automatically when a message is opened (no offer, translation shown right away, "Оригинал" available). Settings UI: a language list picker like the never-translate one. Controller API: `alwaysTranslateFrom(String lang)` / `neverTranslateFrom(String lang)` (the latter may exist — reuse) so the lead can put them into U2's translation chip menu. Do not edit the `MailTranslateStrip` widget (U2 owns it) beyond what is needed to compile.
4. Keep `refineCyrillicLang`, `mainScriptSample`, `languageSample` behaviour; extend the existing tests.

## Tests
Unit tests for the offer decision (confident vs weak, phone languages, never/always lists, app language); controller test with a fake translator (always-translate shows the translation without an offer; weak guess → no offer, explicit translate still works). Settings section widget test for the two new controls.
