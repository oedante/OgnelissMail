# «Что нового» — 2.3.2 (150)

Исправления по журналам владельца и пользователей 10–12.11.2026. Шаги
владельца — `OWNER_STEPS_2.3.2.md`.

## Сделано

- **Проверка почты вовремя во всех режимах (Android).** Будильник системы
  к сроку ближайшего ящика — и в глубоком сне; у ящиков «раз в 15 минут /
  30 / час» он на несколько секунд поднимает службу почты. Раньше без
  службы проверки откладывались на час-два.
- **Яндекс: письмо есть на сервере, а в приложении нет** — сверка новых
  писем со списком сервера, пропущенные догружаются.
- **Яндекс, Mail.ru, Yahoo: отправленные — в «Отправленных»** (сервер
  копию не кладёт — приложение сохраняет её само, без дублей).
- «Список папок» не висит по три минуты.
- Имя-спам («Вам перевод … https://…») больше не подставляется как имя
  получателя; свои адреса — именем ящика.
- Листание писем — намеренным жестом вбок.
- В уведомлении — ящик, на который пришло письмо.
- Стандартные папки (Sent и др.) — на языке приложения.
- Планшет и компьютер: блок разделов не съезжает к середине.
- Без точки у непрочитанных; маскировка шлюза — отдельные User-Agent для
  EWS и ActiveSync.
- Сборка: Android Gradle Plugin 9.1.1 (Flutter 3.50).

## Для магазинов

**RU.** Почта проверяется вовремя и в спящем режиме телефона. Яндекс:
отправленные письма появляются в «Отправленных», письма не теряются при
синхронизации. В уведомлении видно, на какой ящик пришло письмо. Названия
папок на вашем языке, аккуратнее листание писем и исправления интерфейса.

**EN.** Mail is checked on time even while the phone sleeps. Yandex: sent
mail appears in Sent, no messages are missed during sync. Notifications
show which mailbox the mail arrived to. Folder names in your language,
steadier paging between messages and UI fixes.
