# Ogneliss Mail 2.7.0 — что сделать владельцу

2.7.0 (171) — номер недели в виджете календаря. В текстах магазинов — и
пункты 2.6.9, которых в её текстах не было: «Ответить» слева, приветствие
по времени суток, свои группы рассылки в подсказках адреса. «Что нового» —
`STORE_NOTES_2.7.0.md`. Ключи, Xcode, база данных и зависимости не
менялись.

## 2. Что проверить

1. **Виджет календаря, «Неделя» (Android).** Слева от дней — «Н47» (номер
   текущей недели); стрелками — номер меняется.
2. **Виджет календаря, «Месяц».** Включите в приложении «Настройки →
   Календарь → Номера недель» — в виджете слева от строк месяца появляется
   столбец номеров (виджет обновляется сам); выключите — столбец пропадает.
   Проверьте оба вида месяца: сетка на весь виджет и сетка со встречами
   выбранного дня под ней (виджет повыше).
3. **Кнопки под письмом** (из 2.6.9): «Ответить» слева; «Настройки → Почта
   → Кнопки под письмом» — первым пунктом «Стандартно», вторым «Под правую
   руку».
4. **Поиск адресата** (из 2.6.9): выберите адресата из подсказки, пока
   крутится «Ищем в адресной книге организации…», — строка пропадает.
   Наберите название своей группы рассылки — она первой в подсказках,
   нажатие добавляет всех участников.
5. **Приветствие** (из 2.6.9): новое письмо утром — «Доброе утро, …»,
   вечером (после 18:00) — «Добрый вечер, …».
