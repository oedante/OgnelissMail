Ogneliss Mail — переносная версия

Пока этот файл лежит рядом с ogneliss.exe, всё, что программа хранит
(почта, настройки, ключи, вложения, журналы, данные встроенного браузера),
записывается в папку UserData рядом с программой, а не в AppData.

Удалите этот файл — программа будет хранить данные в AppData, как обычно.

Ключи защищены средствами Windows (DPAPI) и привязаны к учётной записи:
на другом компьютере или под другим пользователем почта загрузится заново,
а ящики нужно будет добавить ещё раз.

---

Ogneliss Mail — portable version

While this file sits next to ogneliss.exe, everything the program stores
(mail, settings, keys, attachments, logs, built-in browser data) is written
to the UserData folder next to the program instead of AppData.

Delete this file and the program stores its data in AppData as usual.

Keys are protected by Windows (DPAPI) and tied to the user account: on
another computer or under another user the mail is downloaded again and
the mailboxes need to be added again.
