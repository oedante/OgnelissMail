# 1.14.0 — что сделать владельцу (05.11.2026)

1.14.0 (139) — это 1.12.0 (138) плюс второй круг доработок 04–05.11.2026
(«Что нового» — `STORE_NOTES_1.14.0.md`). Номер — решение владельца
05.11.2026 («Давай версию 1.14.0 сделаем»); 1.13 не выпускалась.

**По сравнению с 1.12.0 у Apple, Google, на сервере и в Xcode ничего нового
делать не нужно.** `project.pbxproj`, `Runner.entitlements` и `Info.plist`
не менялись, новых прав и возможностей нет. На Android одно разрешение
убрано (`READ_EXTERNAL_STORAGE` — приложение его никогда не спрашивало,
оно приходило из библиотеки open_filex) и добавлены два `<queries>` (поиск
сервисов Google и приложений UnifiedPush) — в Play Console ничего заполнять
не нужно. Если шаги из `OWNER_STEPS_1.11.0.md` ещё не сделаны, сначала
сделайте их (ключ APNs и Firebase, сервер, политика на сайте, секреты
GitHub, Push Notifications в Xcode).

Новая зависимость — пакет `markdown` 7.3.1 (команда Dart, BSD-3-Clause,
бесплатно): показ вложений .md. Строка — в `LICENSING.md`, раздел 2; текст
лицензии приложение показывает само (Настройки → О приложении → Тексты
лицензий).

Новое для вас:

- сборка с номером 139 (Android и iOS);
- тексты «Что нового»;
- проверка на телефонах (шаг 4) — по семействам устройств;
- решение о перетаскивании вложений из окна наружу (шаг 5).

Архив исходников — `ogneliss-mail-1.14.0+139.zip`:

- распаковывается поверх прежней папки проекта;
- настройки Xcode не затирает (файлы проекта Xcode лежат в `ios/xcode-base/`
  и берутся, только если своих нет);
- `config/dart_defines.json` в архиве нет (это секреты): берите прежний.

## 1. Android

**Вариант А — GitHub (без своей сборки).** Метка `v1.14.0` на `main`:

1. Откройте GitHub → **Releases** → **Draft a new release**.
2. **Choose a tag** → `v1.14.0` → Target `main` → **Publish release**.
   Или в терминале: `git tag v1.14.0 && git push origin v1.14.0`.

Сборка соберёт APK и App Bundle (`.aab`) и выложит страницу выпуска с «Что
нового». App Bundle — в артефакте `ogneliss-android-…` задачи сборки в
Actions. Подробно — `OWNER_STEPS_1.11.0.md`, шаг 1, «Выпуск — метка».

**Вариант Б — у себя** (Android Studio или терминал в папке проекта,
`config/dart_defines.json` и ключ подписи `android/key.properties` — как
раньше):

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter build appbundle --release --dart-define-from-file=config/dart_defines.json
```

App Bundle — `build/app/outputs/bundle/release/app-release.aab`.

**Google Play Console:**

1. Ogneliss Mail → **Тестирование → Внутреннее тестирование** (или сразу
   **Рабочая версия**) → **Создать выпуск** → загрузить `.aab`.
2. «Что нового» — блок «Google Play — все 27 языков» из
   `STORE_NOTES_1.14.0.md`: скопировать целиком, от `<ru-RU>` до последнего
   закрывающего тега, в одно поле.
3. Рабочая версия — поэтапно, сначала 10–20 %.

## 2. iPhone и iPad: сборка на Mac и TestFlight

Нужен Mac с Xcode (последняя версия из App Store), Flutter 3.38 или новее и
CocoaPods. Окружение один раз — `guides/BUILD_IOS.md`, вариант А, шаг 1.

### 2.1. Папка проекта

1. Распакуйте `ogneliss-mail-1.14.0+139.zip` **поверх** прежней папки
   `ogneliss-mail` (Finder: «Заменить», или в Терминале
   `unzip -o ogneliss-mail-1.14.0+139.zip -d ~/` при распаковке в домашнюю
   папку).
2. Проверьте, что на месте `config/dart_defines.json` — тот же файл, что
   для Android.

### 2.2. Сборка

В Терминале:

```bash
cd ~/ogneliss-mail
chmod +x scripts/*.sh
scripts/build_ios.sh --check      # Xcode, Flutter, CocoaPods
scripts/build_ios.sh              # → build/ios/ipa/*.ipa
```

Скрипт сам выполнит `flutter pub get` (скачает и новый пакет `markdown`),
сгенерирует код базы (`build_runner`) и `pod install`. Подпись — как
раньше (`~/.ogneliss/ios_signing.xcconfig`, архив её не трогает). Номер
сборки 139 и версия 1.14.0 берутся из `pubspec.yaml` сами.

### 2.3. Отправка в TestFlight — один из способов

- **Transporter** (бесплатное приложение Apple из Mac App Store): войти
  своим Apple ID → перетащить `build/ios/ipa/*.ipa` → **Deliver**.
- **Xcode:** **Window → Organizer** → **Archives** → архив 1.14.0 (139) →
  **Distribute App** → **App Store Connect** → **Upload**. Архив —
  `build/ios/archive/Runner.xcarchive`, если в Organizer его нет: открыть
  его двойным щелчком.
- **Из Терминала** с ключом App Store Connect API (если он у вас есть):
  ```bash
  ASC_KEY_ID=XXXXXXXXXX ASC_ISSUER_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx \
    scripts/build_ios.sh --upload
  ```

Если сборка или подпись не проходит — таблица «Если не собирается» в
`guides/BUILD_IOS.md`.

### 2.4. App Store Connect

1. Через 10–30 минут сборка 139 появится в **TestFlight**. На вопрос о
   шифровании ответьте так же, как для прежних сборок.
2. **TestFlight → группа открытого тестирования** → **«+» Сборки** → 139.
   Поле «Что тестировать» — например:
   `Сведения о письме значками, вложения .txt и .md, письма Outlook .msg,
   поиск по тексту вложений, перевод «всегда с языка», iPad: область чтения
   снизу или скрыта, выбор писем с Cmd и Shift.`
3. Для выпуска в App Store: **Распространение → iOS-приложение → «+»
   Версия** → `1.14.0` (неотправленную 1.12.0 — переименовать в 1.14.0),
   сборка 139.
4. «Что нового в этой версии» — блоки `<ru-RU>`, `<en-US>`, `<de-DE>`,
   `<fr-FR>` из раздела «App Store» файла `STORE_NOTES_1.14.0.md`, каждый —
   в свою локализацию (без строк с тегами).
5. Notes, демо-ящик и видео для проверяющих — `APP_REVIEW_NOTES.md`.

## 4. Проверить на телефонах

Файлы удобно прислать себе письмом. Образцы — в архиве в
`test/fixtures/office/`.

### 4.1. Лента и письмо (любой телефон)

1. **Свайпы:** протяните письмо на треть ширины и отпустите — строка
   возвращается на место (раньше застревала на середине); протяните дальше
   — действие выполняется. При двух действиях на стороне кнопки остаются
   открытыми, но только у одного письма: свайп другого закрывает прежнее.
2. **Значки под заголовком письма:** письмо-рассылка (значок отписки),
   письмо с картинками (значок «Показать изображения»), письмо на другом
   языке (значок «Перевести · …»). Нажатие раскрывает подробности, повторное
   — сворачивает; «▾» или долгое нажатие — остальные варианты.
3. **Перевод:** у значка перевода «▾» → «Всегда переводить с языка …» —
   следующее письмо на этом языке открывается уже в переводе; русское и
   английское письма (языки телефона) — без предложения перевода.
4. **Вложения:** `.txt` в Windows-1251 — читается по-русски; `.md` —
   оформленным документом (заголовки, списки, таблицы). На iPhone они
   теперь тоже открываются в приложении.
5. **Поиск по вложениям:** откройте письмо с документом, затем найдите
   слово, которое есть только в документе, — письмо находится со строкой
   «Во вложении: …». Выключается: Настройки → Почта → «Искать в тексте
   вложений».

### 4.2. Уведомления и фон — по семействам устройств

- **nubia/ZTE (Android 15, ваш телефон):** удалить приложение и поставить
  заново.
  - После входа в ящик — один экран: уведомления, «Батарея», точные
    напоминания, «Ограничения nubia». «Разрешить всё» открывает системные
    экраны по очереди и в конце — экран автозапуска nubia/ZTE.
  - Контактов и календаря на этом экране нет (их спрашивают, когда
    включаете «В телефоне»).
  - Свернуть приложение, выключить экран на 30–60 минут — письма приходят.
- **Pixel, Motorola:** тот же экран, но без строки производителя.
  «Настройки → Уведомления → Сигналы сервера» — «Зарегистрировано…».
- **Samsung, Xiaomi/HyperOS, OPPO/OnePlus/realme, vivo, Honor/Huawei:**
  кнопка строки производителя открывает экран автозапуска или фона именно
  этой оболочки (если его нет — сведения о приложении). После
  перезагрузки, не открывая приложение, письмо приходит в пределах 15–30
  минут.
- **Huawei/Honor без Google, LineageOS, GrapheneOS, CalyxOS, /e/OS:**
  - без ntfy — под «Сигналами сервера» строка «Без сервисов Google почта
    проверяется по расписанию…», без «Не удалось»; пункта «Через Google»
    нет;
  - на LineageOS, поставленной на Xiaomi или Samsung, нет подсказки про
    автозапуск производителя;
  - поставить ntfy — он выбирается сам, «Зарегистрировано…», приходит
    «Последний сигнал»; с двумя такими приложениями — строка «Выберите
    приложение для сигналов»;
  - «Выгрузить встречи в календарь» на телефоне без календарей создаёт
    календарь «Ogneliss Mail»;
  - **перевод письма** (скачивание языков) — напишите, работает ли он без
    сервисов Google: ML Kit скачивает языки с серверов Google, и без Play
    Services это не проверено.
- **microG без «Облачных сообщений»:** сигналы через ntfy, без ошибки.
- **Любой Android:** «Разрешения → Батарея» открывает настройку и на
  оболочке без списка оптимизации; в «Сведениях о приложении →
  Разрешения» нет «Файлы и медиа»; «В телефоне → Контакты» после «Больше
  не спрашивать» предлагает открыть настройки.
- **MDM «скрывать текст уведомлений»:** отложить письмо («Посмотреть
  позже») — в напоминании нет отправителя и темы.
- **iPhone и iPad:** новая установка — на заставке нет системного вопроса
  об уведомлениях; он появляется в шаге после входа в ящик. Отказать —
  в ленте строка «Уведомления выключены · Включить».

### 4.3. Планшет и компьютер

1. Настройки → Оформление → «Область чтения»: «Снизу» — лента сверху,
   письмо под ней, разделитель тянется и запоминается; «Скрыта» — письмо
   открывается отдельным экраном. То же — в меню «⋮» над лентой.
2. С клавиатурой и мышью: Ctrl+нажатие (Mac и iPad — Cmd) — по одному
   письму, Shift — подряд, Ctrl+A — все, Esc — снять выбор, Delete —
   удалить выбранные.
3. Вложение из письма в области чтения открывается в ней же, «Назад» —
   к письму.

## 5. Решение: перетаскивание вложения из окна наружу

Встроенного способа во Flutter нет. Варианты (подробно — отчёт в
`HANDOFF.md`, раздел 1.14.0):

- пакет **super_drag_and_drop** (MIT) — самый полный, но ядро на Rust:
  либо Rust на каждой машине сборки, либо скачанные готовые библиотеки, на
  Android — NDK; нужно ваше согласие на зависимость;
- **свой небольшой плагин** без зависимостей — сначала Windows и macOS;
- **«Копировать файл»** (пакет pasteboard, Apache-2.0) — вставить в
  Проводник или Finder, как временная замена.

Скажите, какой вариант делать, — без вашего решения ничего не добавлено.
