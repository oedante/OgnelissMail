# Ogneliss Mail

[English](README.md) · **Русский**

**Почта с открытым кодом, которую можно проверить.** Почта, календарь,
контакты и задачи для Microsoft Exchange (ActiveSync и EWS) и ящиков
IMAP/SMTP, календари и контакты по CalDAV/CardDAV. Android, iPhone и iPad;
сборки для Windows, macOS и Linux — предварительные.

> **Не верьте нам на слово — проверьте.** Почтовая программа видит самую
> личную переписку, поэтому ничего ниже не нужно принимать на веру: каждое
> утверждение можно проверить в этом репозитории.

Сайт: https://ogneliss.ru/mail/

**Загрузки:** [GitHub Releases](https://github.com/oedante/OgnelissMail/releases)
— Android (APK), Windows, macOS и Linux: собраны GitHub Actions из коммита с
меткой версии, с `SHA256SUMS.txt` и подтверждением происхождения сборки.
Тестирование Android в Google Play: https://play.google.com/apps/testing/com.ogneliss.mail

## Принципы

- **Открытый код.** Приложение, почтовый движок и оба сервера — здесь, под
  лицензией Apache 2.0.
- **Прямое подключение.** Письма идут между вашим устройством и вашим
  почтовым сервером и никогда не проходят через серверы Ogneliss.
- **Данные на устройстве.** Почта хранится на устройстве в зашифрованной
  базе.
- **Без рекламы и аналитики.** Ни рекламных, ни следящих SDK, ни телеметрии,
  ни сборщиков отчётов о сбоях.
- **Бесплатно.** Без подписок, платных версий и платных функций.

## Проверьте сами

| Утверждение | Где смотреть |
|---|---|
| Нет рекламы, аналитики и слежки | `pubspec.yaml` и `android/app/build.gradle.kts` — полный список зависимостей |
| Почта идёт прямо на ваш сервер | `packages/mail_engine` — Exchange ActiveSync, EWS, Microsoft Graph (Exchange Online), IMAP/SMTP; `lib/core/network` — HTTP-клиенты и проверка сертификатов |
| Зашифрованное хранение на устройстве | `lib/data/database/app_database.dart` — SQLite3 Multiple Ciphers; ключ хранится в защищённом хранилище ОС |
| Что делают серверы автора | `server/oauth-proxy` (обмен кода OAuth, токены в памяти не дольше 2 минут) и `server/push-relay` (пустые сигналы «проверь почту» для iPhone); [политика конфиденциальности, раздел 6](https://ogneliss.ru/mail/privacy#oauth) |
| Файлы выпусков | GitHub Actions собирает их из коммита с меткой, журнал сборки открыт; у каждого файла — подписанное подтверждение происхождения: `gh attestation verify <файл> --repo oedante/OgnelissMail`, контрольные суммы — в `SHA256SUMS.txt` |

Сборки Google Play и App Store делаются из того же кода, но с ключами подписи
и клиентами OAuth автора, которых в репозитории нет, поэтому побайтно их не
сравнить.

## Возможности

- **Microsoft Exchange** по ActiveSync и EWS, Exchange Online — ещё и через
  Microsoft Graph (адресная книга, подсказки, правила сервера): почта,
  календарь, контакты, задачи и заметки, ответы на приглашения, автоответы, адресная книга
  организации, подсказки MailTips, общие и делегированные ящики, правила
  сервера, политики устройства и удалённая очистка.
- **Любой ящик IMAP/SMTP** — Gmail, Outlook.com, Яндекс, Mail.ru, iCloud и
  другие; вход через OAuth или пароль приложения; CalDAV и CardDAV.
- **Каждый день:** «Мой день», контроль и отложенные письма, цепочки (любую
  можно оставить без уведомлений), отмена отправки, отправка по расписанию,
  правила, VIP и тихие часы, виджеты.
- **Архив Ogneliss:** зашифрованный архив на устройстве — письма с
  вложениями и структурой папок, встречи, задачи, контакты и настройки;
  поиск по архиву, копия для другого устройства.
- **Безопасность:** S/MIME, предупреждения о фишинге и внешних отправителях,
  блокировка трекеров, PIN-код и вход по биометрии.
- 27 языков интерфейса; шрифт интерфейса на выбор — Roboto или Medeo Sans.

## Сборка

Нужно: Flutter (stable), Android SDK / Xcode — по платформе.

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run --dart-define-from-file=config/dart_defines.json
```

В `config/dart_defines.json` — ваши клиенты OAuth и адреса серверов; в
репозиторий файл не входит (пример — `config/dart_defines.example.json`),
см. `docs/guides/OAUTH_SETUP.md` и `docs/guides/QUICKSTART.md`. Руководства
по платформам — `docs/guides/`. Своя версия под своим названием —
`docs/guides/OWN_VERSION.md`.

Строки интерфейса — `assets/l10n/<код>.xml`; инструмент —
`tool/l10n/l10n.py`.
