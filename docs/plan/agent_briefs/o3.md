# Task O3: presentations — PPTX, ODP → slides drawn with Flutter widgets

Shared rules: [o_common.md](o_common.md) (read it first) and [common.md](common.md).

## Model and API
`lib/services/documents/doc_slides.dart` (pure Dart): `class OfficeSlidesDoc extends OfficeDoc` with slide size in points (`width`, `height`), `final List<DocSlide> slides`, `truncated`. Design the rest yourself, roughly: `DocSlide` (background colour and/or image, shapes in z-order); `DocShape` (box x/y/w/h in points, rotation, flips, geometry kind — rect, round rect, ellipse, line, other → rect; fill colour, line colour/width, image `OfficeImage` with optional crop, text body: insets, vertical anchor, autofit font scale, paragraphs; or a table); `DocParagraph` (alignment, level, bullet text or auto-number, indent, spacing, line spacing, runs); `DocRun` (text, bold, italic, underline, strike, size pt, colour, super/subscript). Colours as 0xAARRGGBB ints.

Readers (exact signatures):
- `lib/services/documents/pptx_reader.dart`: `class PptxReader { static OfficeSlidesDoc read(OfficeZip zip); }`
- `lib/services/documents/odp_reader.dart`: `class OdpReader { static OfficeSlidesDoc read(OfficeZip zip); }`
Caps (documented constants): ~300 slides, ~500 shapes per slide, images within `OfficeZip.image` budgets; beyond → `truncated`.

## PPTX (ECMA-376 PresentationML + DrawingML)
`presentation.xml`: sldSz (EMU → pt: /12700), sldIdLst order (r:id via rels); hidden slides (`show="0"`) skipped. Slide → its layout → master → theme (clrScheme, fontScheme) via rels. Placeholders (p:nvPr/p:ph type/idx) without their own a:xfrm take position from the layout placeholder (match idx, then type), then the master. Text property inheritance (as far as practical): run rPr ← paragraph pPr/defRPr ← shape lstStyle ← layout placeholder lstStyle ← master placeholder lstStyle ← master txStyles (titleStyle / bodyStyle / otherStyle, lvl1pPr…lvl9pPr) ← presentation defaultTextStyle. Colours: srgbClr, schemeClr (with the master clrMap: tx1/bg1 → dk1/lt1 …), sysClr lastClr, prstClr; modifiers lumMod/lumOff/tint/shade/alpha. Background: p:bg/p:bgPr (solidFill, gradFill → a middle stop, blipFill image), p:bgRef (theme bgFillStyleLst + colour), else layout/master background. Shapes: p:sp (spPr xfrm off/ext/rot/flipH/flipV, prstGeom, solidFill/noFill/gradFill, a:ln w + fill; p:style fillRef/lnRef/fontRef when spPr has none), txBody (bodyPr anchor t/ctr/b, insets, normAutofit fontScale/lnSpcReduction, wrap="none"), paragraphs (algn, lvl, marL/indent, buChar/buAutoNum/buNone/buFont, spcBef/spcAft, lnSpc), runs (sz, b, i, u, strike, baseline, solidFill, a:br, a:fld text). p:pic (blipFill a:blip r:embed via `zip.image`, srcRect crop). p:graphicFrame with a:tbl (tblGrid, tr h, tc gridSpan/rowSpan/hMerge/vMerge, txBody, tcPr fill; tableStyleId — a plain fallback look is fine); charts and SmartArt → a neutral placeholder box (or SmartArt's cached drawing part `ppt/diagrams/drawing*.xml` if simple). p:grpSp with grpSpPr off/ext/chOff/chExt child transform, nested (depth cap). mc:AlternateContent: prefer mc:Fallback when it holds a picture, else mc:Choice; never both. Notes — skip.

## ODP (OASIS OpenDocument presentation)
`content.xml` office:presentation/draw:page (presentation:visibility hidden → skip; draw:style-name → drawing-page-properties background draw:fill/draw:fill-color/fill image; draw:master-page-name → `styles.xml` style:master-page: page layout size fo:page-width/height, and the master's non-placeholder shapes drawn under the slide). Shapes: draw:frame (svg:x/y/width/height, draw:transform rotate/translate) with draw:text-box, draw:image (xlink:href via `zip.image`), table:table, draw:object (chart → placeholder); draw:custom-shape (draw:enhanced-geometry draw:type rectangle/round-rectangle/ellipse/…) with text; draw:rect, draw:ellipse, draw:line (x1/y1/x2/y2), draw:polygon/draw:path (bounding box), draw:g (children already absolute). Styles: draw:style-name / presentation:style-name → style:graphic-properties (draw:fill none/solid, draw:fill-color, draw:stroke none/solid, svg:stroke-color, svg:stroke-width, draw:textarea-vertical-align, fo:padding-*), text styles as in ODT (fo:font-size, fo:font-weight, fo:font-style, fo:color, fo:text-align, underline/line-through), lists (bullets). Units cm/mm/in/pt/pc/px → pt. `zip.odfMimeType` (presentation or template; else damaged), `zip.odfEncrypted` (→ encrypted).

## Viewer widget
`lib/features/mail/widgets/doc_slides_view.dart`: `class DocSlidesView extends StatelessWidget/StatefulWidget { const DocSlidesView({super.key, required this.doc}); final OfficeSlidesDoc doc; }`; fills the space it gets (inside a PageView page of the attachment screen — do not fight its horizontal swipes in the list mode).
- Slides as a lazy vertical list of "paper" cards with the deck's aspect ratio, as wide as the screen (capped, e.g. 960 px on desktop/tablet), slide number under each ("3 / 12", Semantics label `l10n.tr('docSlideOf')` with {n} and {total}).
- Each slide is a fixed-size `Stack` in slide points scaled by `FittedBox`/`Transform` — fonts and positions scale together; shapes as `Positioned` with `Transform.rotate`; fills/lines/ellipses/round rects via decorations or a painter; text via `Text.rich` (allow overflow past the box like PowerPoint, clip at the slide edge); images with `Image.memory` decoded near display size (`cacheWidth`/`ResizeImage`) and only for visible slides; tables via `Table`.
- Tap a slide → full-screen view: PageView over slides with pinch zoom (InteractiveViewer) and the slide counter; back returns to the list.
- Slides keep their own colours in the dark theme (white paper stays white); the area around slides follows the theme.
