# Погода в «Моём дне»: условия сервисов, решение владельца, переключение

Сделано 07.11.2026 (1.15.1, просьба владельца «в мой день добавить
переворачивающиеся часы и погоду»). Часы работают сразу. **Погода в
сборке выключена, пока владелец не примет условия двух сервисов**
(раздел 1). Код: `lib/services/weather/weather_service.dart`,
`lib/features/my_day/weather_view.dart`.

## 1. Что нужно от владельца (до включения погоды)

Условия обоих сервисов прочитаны 07.11.2026 по первоисточникам (из
облачной сессии, с открытым доступом к сайтам). В обоих есть пункт,
который выполнить может только человек:

- **MET Norway, Terms of Service** (https://api.met.no/doc/TermsOfService,
  редакция 05.11.2026), раздел «Use of AI agents»: условия — юридически
  обязывающее соглашение, его должен прочитать, понять и принять человек
  с полномочиями до начала использования сервиса. Если код писал ИИ,
  отвечает за соблюдение условий разработчик.
- **Nominatim Usage Policy**
  (https://operations.osmfoundation.org/policies/nominatim/), раздел
  «Usage in LLMs»: публичный сервис можно использовать, только если
  разработчик сам осознанно решил его использовать и сам отвечает за
  соблюдение правил.

Главные ограничения, которые вы принимаете:

| | MET Norway (прогноз) | Nominatim (поиск города) |
|---|---|---|
| Плата | бесплатно, SLA нет | бесплатно, «очень ограниченная мощность», серверы на пожертвования |
| Лимит | 20 запросов/с на всё приложение (все установки вместе) | 1 запрос/с на всё приложение; «умеренное число пользователей» |
| Опознание | User-Agent с названием и адресом проекта — есть | User-Agent — есть |
| Частота | не раньше Expires, If-Modified-Since, не опрашивать в фоне — так и сделано | только по действию человека; без подсказок на каждую букву; одинаковые запросы не повторять — так и сделано |
| Подпись | CC BY 4.0: источник и ссылка на лицензию — есть в окне погоды | «© участники OpenStreetMap» — есть в окне поиска, со ссылкой |
| Переключение | — | приложение должно уметь сменить сервис по их просьбе **без обновления** — сделано, раздел 2 |
| Личные данные | IP пользователя и координаты пишутся в журналы MET (Осло); советуют свой прокси | политика конфиденциальности OSMF; личные данные не передавать |
| Рост | при большом трафике — обязателен свой кэширующий прокси | при росте — свой Nominatim или платный поставщик |

**Как включить.** Скажите «условия MET Norway и Nominatim прочитал,
принимаю» — я поставлю `WeatherApi.termsAccepted = true`
(`lib/services/weather/weather_service.dart`), или поставьте сами. До
этого у пользователей нет ни кнопки погоды, ни одного запроса к этим
сервисам.

Если условия не подходят, есть другой путь: свой небольшой прокси погоды на
вашем сервере (рядом с `server/push-relay`). Он кэширует прогноз по
округлённым координатам для всех пользователей, а IP пользователей в MET не
уходит. Поиск города при этом — офлайн-список городов GeoNames (CC BY 4.0,
около 2–3 МБ в приложении) вместо Nominatim. Работы — день-два.

## 2. Переключение без обновления приложения: services.json

Приложение перед запросом погоды или поиском города читает (не чаще раза в
сутки) файл **https://ogneliss.ru/mail/services.json**:

```json
{
  "weather": {
    "forecast": "https://api.met.no/weatherapi/locationforecast/2.0/compact",
    "geocoder": "https://nominatim.openstreetmap.org/search"
  }
}
```

- Адрес `https://…` — замена (сервис с тем же форматом ответа, например
  свой прокси или свой Nominatim). Только https и без параметров в адресе;
  иначе — адрес по умолчанию.
- Пустая строка `""` — сервис выключен: прогноза нет, или в окне поиска
  «Поиск города сейчас недоступен».
- Файла нет (404) или ключа нет — адреса по умолчанию (как выше).
- Сайт недоступен — последние полученные адреса.

Файл не обязателен. Его стоит выложить с адресами по умолчанию, чтобы при
просьбе OSMF или MET Norway изменить одну строку. В архиве сайта он
кладётся рядом со страницами `mail/` (рядом с `privacy`, `terms`).

## 3. Текст для политики конфиденциальности (ogneliss.ru/mail/privacy)

Добавить раздел (после включения погоды):

> **Погода в «Моём дне» (по желанию).** Погода выключена, пока вы не
> выберете город. Местоположение устройства не используется. Для поиска
> города его название отправляется в сервис Nominatim (OpenStreetMap
> Foundation, Великобритания). Для прогноза координаты выбранного города,
> округлённые примерно до 1 км, отправляются в сервис MET Norway
> (Норвежский метеорологический институт, серверы в Осло). Как при
> открытии любого сайта, эти сервисы видят IP-адрес устройства; MET Norway
> хранит его в журналах вместе с координатами запроса. Раз в сутки
> приложение читает с ogneliss.ru список адресов этих сервисов. Других
> данных о вас и вашей почте в эти сервисы не уходит. Организация может
> запретить погоду через MDM (ключ `block_weather`).

## 4. Проверено в облачной сессии 07.11.2026

- Настоящий ответ Locationforecast для Казани (`lat=55.7964&lon=49.1088`):
  разбирается приложением (температура, значки, 12 часов вперёд);
  `Expires` — около 30 минут; повтор с `If-Modified-Since` даёт 304.
- Тексты условий — разделы выше; лицензия данных — NLOD 2.0 и CC BY 4.0
  (https://api.met.no/doc/License). Значки погоды в приложении — свои
  (Material Symbols), значки Yr (MIT) не используются.
