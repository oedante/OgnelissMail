## iOS (local notifications; there is no notification service extension)
- Communication Notifications: when posting a mail notification, create an INSendMessageIntent with the sender as INPerson (display name, email handle, INImage from contact photo or generated initials), donate the INInteraction, and update the UNNotificationContent from the intent (`content.updating(from: intent)`) so iOS shows the sender's avatar like messengers. Requires: posting these notifications natively (a MethodChannel in an existing Swift file of the Runner target, e.g. AppDelegate.swift — do NOT add new Swift files, they would need a project.pbxproj change), Info.plist NSUserActivityTypes containing INSendMessageIntent (Info.plist may be edited), and the "Communication Notifications" capability (entitlement com.apple.developer.usernotifications.communication) — which the OWNER must enable in Xcode. Write Russian step-by-step instructions to docs/guides/IOS_COMMUNICATION_NOTIFICATIONS.md and make the code degrade gracefully (normal notification) when the entitlement is missing or iOS < 15.
