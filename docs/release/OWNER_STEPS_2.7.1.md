# Ogneliss Mail 2.7.1 — что сделать владельцу

2.7.1 (172) — один повтор события Google (день рождения из контактов)
удаляется без ошибки. В текстах магазинов — и пункты 2.7.0, которых в её
текстах не было: проверка почты в фоне, контакты и календарь в телефоне —
сами; письма людей и коллег — как в мессенджере, рассылки — простыми
уведомлениями; встречи Google сразу после «обновить». «Что нового» —
`STORE_NOTES_2.7.1.md`. Ключи, Xcode, база данных и зависимости не
менялись.

## 1. Тег для сборки на GitHub: `v2.7.1`

После слияния PR в `main`:

```bash
git tag -a v2.7.1 -m "Ogneliss Mail 2.7.1" origin/main
```
```bash
git push origin v2.7.1
```

## 2. Что проверить

1. **День рождения из контактов Google.** Ящик Gmail, календарь: откройте
   день рождения контакта → «Удалить» — ошибки нет, этот год пропадает из
   календаря Ogneliss, следующий год — на месте. Потяните «обновить» —
   удалённый год не возвращается. В календаре Google день рождения
   остаётся (Google не даёт менять даты дня рождения из контактов; убрать
   его совсем — в карточке контакта).
2. **Обычная повторяющаяся встреча Google.** Создайте серию (например,
   каждый день), удалите одно вхождение в Ogneliss — пропадает и в
   календаре Google.
3. **Уведомления** (из 2.7.0): письмо коллеги или знакомого с Gmail —
   уведомлением с портретом отправителя, как в мессенджере; рассылка
   (магазин, новости) — простым уведомлением.

Остальное, сделанное после архива 2.7.1, — в `OWNER_STEPS_2.7.2.md`.

## 3. Базовый профиль запуска

Как в 2.7.0: снимается в CI и лежит в
`android/app/src/main/baselineProfiles/`, делать ничего не нужно.
