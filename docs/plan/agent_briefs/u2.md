# Task U2: message notices as one row of chips ("таблетки") instead of stacked banners

Owner (04.11.2026): "Мне не нравится несколько плашек с предложением отписаться, предложение перевода и что-нибудь ещё. Съедают место. Может сделаем это таблетками с раскрытием по нажатию". Proposal accepted. Rules: [r2_common.md](r2_common.md).

## Today
`lib/features/mail/screens/mail_detail_screen.dart`, the block between the header and the body (search for "Антифишинг", "Отписаться", "Внешние изображения скрыты", "MailTranslateStrip"): up to ~15 stacked banners — `SenderSafetyBanner`, `MeetingInviteBanner`, booking card, `_restoreBanner` (spam/trash), `_smimeEncryptedBanner`, `_smimeSignatureBanner`, `_controlBanner` ("На контроле"), `_laterBanner` ("Позже"), `UnsubscribeBanner`, high-importance banner, tags/categories chips row, `ReadReceiptBanner`, `DeliveryStatusBanner`, the blocked-images strip, `MailTranslateStrip`. Each takes a full-width line or more.

## Wanted
- **One row of chips under the message header** ("строка сведений"), visually like the existing tags row (ActionChip, compact): e.g. «Перевести · английский», «Отписаться», «Картинки скрыты», «На контроле до 12:00», «Позже: завтра», «Подпись ✓», «Важное», «Не доставлено», «Уведомление о прочтении», «Спам», plus the message tags/categories. Phone: a single line that scrolls sideways (with the existing edge fade, `scroll_edge_fade.dart`); tablet/desktop reading pane: wraps if needed.
- **Tap expands** the full notice right under the row — the same content and buttons the banner has today (reuse the banner widgets/builders as the expanded body; do not rewrite their logic). One expanded at a time; tap again (or another chip) collapses it. Animate softly, respect "reduce motion".
- **Chips with one obvious action do it directly** (as today's single button): translation (Перевести ↔ Оригинал) and blocked images (Показать). Their extra options (never translate this language, always from this domain, what was blocked, choose language…) open from a small trailing "▾" on the chip or a long press, using the app's menu/sheet components.
- **Stay full cards (not chips):** the sender-spoofing warning (`SenderSafetyBanner`, security must stay visible), the meeting invitation, the booking card — they are content with reply buttons.
- **Tone:** neutral (surfaceContainerHigh) by default; warning tone (error colour tint) for "Не доставлено", bad/expired S/MIME signature; info tone (primary tint) for translation offer. Icons from `AppIcons`. Tooltips on hover (desktop). Semantics: each chip announces its full text; expanded state announced.
- Order: actionable first (translation, unsubscribe, images, read receipt), then state (control, later, delivery, S/MIME, importance, spam), then tags/categories.
- Nothing else in the screen changes (body, attachments strip, command bar, reply bar). No new settings.
- T2 changes translation logic in parallel (offer only on confident detection, "always translate", phone languages). Use only the public API of `MailTranslationController` that exists now (phase, from/to names, translate/showOriginal, existing menu actions); the lead will wire T2's new actions into your chip menu at merge.
