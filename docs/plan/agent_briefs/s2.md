# Task S2: search finds text inside attachments

Owner (04.11.2026): accepted («поиск по тексту вложений»). Rules: [r2_common.md](r2_common.md); document security rules of [o_common.md](o_common.md) apply.

## Today
The search index already has a column for it: `emails_fts(... attachments_text ...)` in `lib/data/database/app_database.dart`, and `indexEmailFts(..., attachmentsText)` accepts it — but nothing fills it. Attachments are downloaded on demand (or in the "full message with attachments" fetch mode) into `AttachmentCacheService` (`lib/services/mail/attachment_cache_service.dart`). Document readers: `OfficeReader.readFile` (`lib/services/documents/office_reader.dart`).

## Wanted
- Extract plain text from downloaded attachments: DOCX/ODT/RTF (HTML → text), XLSX/ODS/CSV (cell texts, row by row), PPTX/ODP (shape texts), TXT/CSV/EML (text), and the old .doc/.xls/.ppt once O4 lands (it goes through `OfficeReader`, so nothing special). PDF — only if a pure-Dart way exists without new dependencies; otherwise skip and say so. Limits: per attachment ~100 KB of text, per message ~300 KB; run in a background isolate (reuse `OfficeReader.readFile`, which already runs in an isolate with a time limit); never block the UI or sync.
- Index: write the text into `attachments_text` of the message's FTS row. `indexEmailFts` must not wipe it when the message is re-indexed later (keep the existing value when the new one is empty). No schema change.
- When: right after an attachment is downloaded/cached (any mode), and a light backfill for already cached attachments (idle/background work, small batches, stops on low battery like other background work if there is such a check).
- Respect the document preview settings? No — search indexing is independent, but respect a new setting «Искать в тексте вложений» (Настройки → Почта, default on); off → nothing extracted, existing text removed.
- Search results: the existing search already queries the FTS table — check that a match in `attachments_text` is returned; if the result row can say «найдено во вложении» cheaply, add it; otherwise say so in the report.

## Tests
Unit tests: extraction per format with fixtures in `test/fixtures/office/`, limits, re-index keeps attachment text, setting off removes it, FTS query finds a word that is only in an attachment.
