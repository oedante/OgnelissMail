# 2.3.2 — что сделать владельцу (12.11.2026)

2.3.2 (150) — 2.3.1 и исправления по журналам 10–12.11.2026.

## Что изменилось

- **Проверка почты вовремя во всех режимах (Android).** Будильник системы
  выставлен всегда, когда включены фоновые проверки, — к сроку ближайшего
  ящика. У ящиков «раз в 15 минут / 30 / час» он на несколько секунд
  поднимает службу почты: так проверка идёт и в глубоком сне телефона.
  Раньше без службы почту проверяли только плановая задача и сигнал
  сервера, а их Android во сне откладывает (журнал 10.11: 16:05 → 17:28 →
  19:39). Подробно — `docs/guides/BACKGROUND_WAKE.md`.
- **Яндекс: письмо на сервере есть, а в приложении нет.** Синхронизация
  IMAP больше не верит счётчику сервера: список новых писем называет сам
  сервер, каждое проверяется, пропущенные догружаются.
- **Яндекс (и Mail.ru, Yahoo): отправленные появляются в «Отправленных».**
  Сервер копию не кладёт — приложение проверяет и сохраняет её само.
- **«Список папок» не висит по три минуты**: 45 секунд и повтор на новом
  соединении.
- **Имя получателя из спама** («Вам перевод … https://…»): текст вместо
  имени не берётся; свои адреса — именем ящика; уже сохранённые плохие
  имена чистятся один раз.
- **Листание писем** — намеренным жестом вбок, а не от лёгкого касания.
- **Уведомления**: в шапке — ящик, на который пришло письмо.
- **Названия папок** («Sent» и др.) — на языке приложения.
- **Планшет и компьютер**: блок разделов в «Календаре» и «Контактах» не
  съезжает к середине.
- Без точки у непрочитанных; маскировка шлюза — свой User-Agent для EWS и
  для ActiveSync (в 2.3.1 после архива).

## Что сделать

1. **Google Play, служба почты.** Описание использования службы
   (`specialUse`) в манифесте дополнено: служба ещё и на несколько секунд
   запускается будильником для плановой проверки почты. В Play Console →
   «Контент приложения» → «Разрешения для служб переднего плана» дополнить
   описание той же фразой: «…and for mailboxes checked on a schedule
   chosen by the user it runs for a few seconds per check, started by an
   alarm, so the scheduled mail check is performed on time in Doze».
2. **Проверить на телефоне** (ящик «раз в 15 минут», телефон от батареи,
   экран выключен на час): в «Настройки → Диагностика → фоновая работа»
   записи «будильник» идут раз в ~15 минут. Разрешение «Будильники и
   напоминания» должно быть выдано (иначе будильник неточный, проверка —
   срочной задачей).
3. **Яндекс**: отправить письмо — оно появляется в «Отправленных»
   приложения и веб-почты (один раз, без дубля).

Сервер, Xcode, разрешения — без изменений. Сборка — как у 2.2.0
(`OWNER_STEPS_2.2.0.md`, разделы 3 и 3а).
